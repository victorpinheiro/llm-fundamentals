# LLM Fundamentals

A comprehensive course on Large Language Model fundamentals, covering everything from basic concepts to advanced enterprise integration.

## 📚 Course Structure

This course is organized into three main sections:

- **Course**: 11 modules covering LLM fundamentals, prompt engineering, evaluation, model selection, RAG, agents, and production deployment
- **Roadmap**: A phased learning path with 9 practical projects
- **Resources**: Glossary, learning journal, teaching notes, and weekly checklists

## 🚀 Getting Started

Open `index.html` in your browser to start the course.

## 📖 Learning Tracks

- **Track A**: Focus on practical implementation and hands-on projects
- **Track B**: Deeper theoretical understanding and research-oriented approach

## 🛠️ Projects

The course includes 9 progressive projects:
- P0: Environment Setup
- P1: First Integration
- P2: Prompt Iteration
- P3: Evaluation Pipeline
- P4: Model Router
- P5: RAG System
- P6: Enterprise Integration
- P7: Agent
- P8: Multi-Agent
- P9: Capstone
