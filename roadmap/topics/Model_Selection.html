Model Selection & Cost/Latency Tradeoffs

Fase: 1 | Semanas: 7–8 | Projeto: P4 — Model Router

PDF: "There is no universally optimal model. Model selection is a Pareto
frontier problem — every deployment has specific accuracy, latency, and cost
constraints."

As 5 Perguntas (PDF) — decore isso

  1. Latência máxima aceitável? (<1s / <5s / <30s / batch)
    → <1s descarta a maioria dos modelos frontier para resposta completa.

  2. Quality floor? (enterprise / best-effort / exploratório)
    → Enterprise: teste os modelos maiores primeiro.

  3. Volume de calls e budget de tokens?
    → Alto volume + tarefa commodity → modelo pequeno.

  4. Precisa de extended reasoning? (math, código, lógica multi-passo)
    → Sim: modelo otimizado para raciocínio.

  5. Dado sensível? Data residency?
    → Sim: região específica, VPC-SC, ou self-hosted.
    → No sua empresa isso quase sempre é "sim".

Tiers (mapeamento conceitual — confirme modelos atuais)

Tier Google Outros Use quando
Frontier Gemini Pro Claude Opus, GPT-4o Análise complexa, decisões críticas
Mid / Fast Gemini Flash Claude Sonnet Maioria dos casos enterprise
Small / Cheap Gemini Flash-Lite Claude Haiku Classificação, roteamento, extração
Reasoning Gemini (thinking) o3, Opus extended Código, lógica multi-passo
Self-hosted — Llama, Mistral Regulado, air-gapped

Padrões de otimização de custo (PDF)

Model Routing (reduz 50–70%)

Input → classificador de dificuldade (modelo barato)
      → fácil?   → Flash-Lite
      → médio?   → Flash
      → difícil? → Pro

Prompt Caching

Cacheia a porção estável do contexto (system prompt, docs de RAG).
Corta custo de input tokens significativamente.

Async Batching

Batch APIs custam ~50% menos. Ideal para: processamento de documentos,
enriquecimento de dados, geração de embeddings — casos típicos de automação interna.

Checklist

  • Sei responder as 5 perguntas para qualquer caso de uso
  • Model router implementado com 3 tiers
  • Medi latência real de 3 modelos na mesma tarefa
  • Calculei custo mensal projetado para cenário realista
  • Testei prompt caching
  • Sei quando batch API é aplicável
