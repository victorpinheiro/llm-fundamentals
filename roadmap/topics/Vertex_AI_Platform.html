Google Vertex AI — Plataforma de Referência

Fase: 1 | Semanas: 1–2 | Projeto: P1 — Vertex AI Foundations

⚠️ Nota de precisão: meu conhecimento vai até maio/2026. O Vertex AI muda rápido.
Trate tudo aqui como orientação conceitual e confirme na doc oficial:
https://cloud.google.com/vertex-ai/docs

Por que Vertex AI e não a Gemini API direta

O perfil da função diz "Google Vertex AI" explicitamente. A diferença importa:

Gemini API (AI Studio) Vertex AI
Auth API key Service account / ADC (IAM)
Billing Conta pessoal Projeto GCP
Compliance Limitado VPC-SC, CMEK, data residency
Governança Básica IAM, audit logs, org policies
Enterprise Não Sim — é por isso que a sua empresa usa

Para uma empresa que lida com pagamentos, PCI-DSS ou outros dados sensíveis, a única
opção viável é Vertex AI. Aprenda com auth de service account desde o começo —
API key não passa no security review.

Conceitos-chave

Autenticação

Não use API keys. Use Application Default Credentials (ADC) ou service account:

gcloud auth application-default login          # dev local
# ou service account em produção
export GOOGLE_APPLICATION_CREDENTIALS=/path/sa.json

Regiões e data residency

Vertex AI é regional. Para uma empresa europeia, europe-west4 ou
europe-west1 provavelmente são relevantes. Isso importa para GDPR.

Confirme: qual região a sua empresa usa? Pergunte ao time de plataforma.

Grounding

Vertex AI oferece grounding nativo (Google Search, Vertex AI Search).
Isso pode substituir parte de um RAG caseiro em alguns casos —
avalie antes de construir do zero. É exatamente a mentalidade da escada
de complexidade do PDF.

Modelos (verificar disponibilidade atual)

Família Gemini: Pro (capacidade), Flash (equilíbrio), Flash-Lite (volume/custo).
Mapeamento conceitual com os tiers do PDF em Model Selection & Cost/Latency Tradeoffs.

Checklist

  • Projeto GCP criado (ou acesso a um projeto de sandbox na sua empresa)
  • Vertex AI API habilitada
  • Autenticação via ADC funcionando (sem API key)
  • Primeira call ao Gemini via Vertex AI SDK
  • Entendi as diferenças entre os modelos Gemini disponíveis
  • Verifiquei qual região/projeto a sua empresa usa internamente
  • Testei grounding nativo (antes de construir RAG próprio)
