Google ADK — Agent Development Kit

Fase: 2 | Semanas: 13–15 | Projeto: P7 — Agente com Google ADK

⚠️ Nota de precisão importante: o ADK é recente e evolui rápido. Meu conhecimento
vai até maio/2026 e não vou escrever assinaturas de API específicas que eu não
possa garantir. Use este arquivo como mapa conceitual e escreva o código real
lendo a doc oficial: https://google.github.io/adk-docs/

Por que o ADK importa neste contexto de trabalho

O perfil da função menciona o ADK três vezes. É o framework central do time.
Não é opcional — é a ferramenta que você vai usar no dia a dia.

O que o ADK é (conceitualmente)

Framework Python (e Java) do Google para construir, avaliar e deployar agentes.
Posicionamento parecido com LangGraph, mas integrado ao ecossistema Google:
Vertex AI, Agent Engine (runtime gerenciado), e ferramentas GCP nativas.

Conceitos que você vai encontrar:

Conceito O que é
Agent Unidade que recebe instruções, tem tools e um modelo
Tools Funções que o agente pode chamar (incl. tools GCP prontas)
Multi-agent Composição hierárquica de agentes
Sessions / State Persistência de contexto entre turnos
Runner Execução local para dev
Agent Engine Runtime gerenciado no Vertex AI para produção
Eval Avaliação integrada de trajetória e resposta

Como estudar (ordem sugerida)

  1. Quickstart oficial — construa o "hello world" antes de qualquer teoria
  2. Tools — como definir tools próprias e usar as prontas
  3. Sessions & state — como o agente lembra contexto
  4. Multi-agent — composição (só depois de single agent funcionar)
  5. Eval — avaliação de agentes (conecta com Evaluation & Testing)
  6. Deploy no Agent Engine — do local pra produção

ADK vs LangGraph — quando usar qual

O perfil da função cita ADK, LangChain e LlamaIndex. Vale saber posicionar:

ADK LangGraph LlamaIndex
Força Nativo GCP/Vertex, deploy gerenciado Controle de grafo de estado Ingestão e retrieval de docs
Use quando Está no ecossistema Google (caso da sua empresa) Precisa de controle fino do fluxo RAG pesado sobre documentos

Aviso do PDF que continua valendo: frameworks escondem o que acontece.
Saiba construir um ReAct loop na mão antes de usar qualquer um deles.
Isso é o que você faz no P7 — Agente com Google ADK — primeiro na mão, depois com ADK.

Recursos

  • 📖 Doc oficial: https://google.github.io/adk-docs/
  • 💻 GitHub: https://github.com/google/adk-python
  • 📖 Agent Engine: https://cloud.google.com/vertex-ai/generative-ai/docs/agent-engine/overview

Checklist

  • Li a doc oficial e conferi a versão atual do ADK
  • Rodei o quickstart oficial com sucesso
  • Construí ReAct loop na mão ANTES de usar o ADK (para entender o que ele abstrai)
  • Defini tools próprias no ADK
  • Entendi sessions e gestão de state
  • Rodei eval de agente no ADK
  • Deployei um agente no Agent Engine
  • Sei explicar quando usar ADK vs LangGraph vs LlamaIndex
