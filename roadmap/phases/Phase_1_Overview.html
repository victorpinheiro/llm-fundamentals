Fase 1 — Vertex AI, Prompting & Evaluation (Semanas 1–8)

Degrau: 1 — Single LLM + prompt + structured output

O PDF é explícito: a maioria dos problemas de qualidade se resolve neste nível.
Engenheiros que pulam essa fase sobre-engenheiram com RAG e agents desnecessários.

Diferença desta versão: foco em Vertex AI / Gemini desde o dia 1, porque é o
stack da função. Você também vai testar Anthropic/OpenAI para comparação, mas o
default é Google.

Semana Tópico Projeto
1–2 LLM Fundamentals + Google Vertex AI — Plataforma de Referência P1 — Vertex AI Foundations
3–4 Prompt Engineering P2 — Prompt Engineering + Structured Output
5–6 Evaluation & Testing P3 — Evaluation Pipeline (CI-ready)
7–8 Model Selection & Cost/Latency Tradeoffs P4 — Model Router

Checklist de saída

  • Autentiquei no Vertex AI com service account (não API key)
  • Fiz calls ao Gemini via Vertex AI SDK
  • Comparei Gemini vs Claude vs GPT na mesma tarefa
  • Entendo tokens, custo e context window na prática
  • System prompt com as 6 seções (ROLE/TASK/CONSTRAINTS/FORMAT/EXAMPLES/FALLBACK)
  • Structured output funcionando (sem regex, nunca)
  • DeepEval rodando no pytest e no CI
  • Model routing implementado com economia medida
  • Conversei com pelo menos 1 pessoa de Legal/Support/Ops sobre toil
