Fase 2 — RAG, Integrações & ADK Agents (Semanas 9–17)

Degraus: 2 (RAG), 3 (Single Agent), 4 (Multi-Agent)

Esta é a fase mais próxima do trabalho real de quem entrega IA. Um perfil típico da função descreve exatamente isso:
"automated support agents, intelligent documentation retrieval, contract review automations".

Semana Tópico Projeto
9–10 RAG — Architecture, Patterns & Failure Modes P5 — RAG sobre Documentação (caso Legal)
11–12 Enterprise Integrations — Slack, Atlassian, Zoom P6 — Enterprise Integrations (Slack + Atlassian)
13–15 Agent Orchestration + Google ADK — Agent Development Kit P7 — Agente com Google ADK
16–17 Agent Orchestration P8 — Multi-Agent (só com evidência)

Nota sobre ordem

Integrações (P6) vêm antes de agentes (P7) de propósito.
Um agente sem tools reais é um exercício acadêmico. Quando você chegar no ADK,
já vai ter Slack e Jira funcionando pra plugar como ferramentas de verdade.

Checklist de saída

  • Sei decidir SE usar RAG (decision framework do PDF)
  • Hybrid search (BM25 + vector + RRF) implementado
  • Todos os RAG failure modes do PDF testados
  • Slack app funcionando (Enterprise Grid considerations entendidas)
  • Jira/Confluence API integrada com auth adequada
  • Google ADK: agente rodando localmente e deployado no Agent Engine
  • Sei quando um agente é desnecessário (e documentei isso)
  • Multi-agent só depois de provar que single agent era insuficiente
  • Alguém de outro time usou algo que eu construí
