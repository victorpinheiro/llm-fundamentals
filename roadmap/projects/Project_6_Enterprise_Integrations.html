P6 — Enterprise Integrations (Slack + Atlassian)

Semanas: 11–12 | Degrau: 2
Tópico: Enterprise Integrations — Slack, Atlassian, Zoom · Security-First Design
Cobre do perfil da função: Slack Enterprise Grid, Atlassian suite, security-first

Por que este projeto existe

Este é o gap mais direto entre a teoria e a prática. O perfil da função cita as ferramentas por nome.
E é o projeto que transforma o RAG do P5 em algo que alguém realmente usa.

O que construir

Bot de Slack que responde perguntas sobre documentação e abre tickets.

Usuário no Slack: /docs qual o prazo de rescisão do contrato padrão?
       ↓
   Slack app (verificação de assinatura)
       ↓
   RAG do P5 (com permissões do usuário)
       ↓
   Resposta no thread, com citação
       ↓
   Botão: "Não resolveu? Abrir ticket no Jira"

Componentes

1. Slack app

  • Slash command /docs
  • Verificação de assinatura de request
  • Resposta em thread (não polui o canal)
  • Block Kit com citação clicável
  • Botão de escalação para Jira
  • Scopes mínimos

2. Atlassian

  • Confluence como fonte de documentos (ingestão)
  • Jira: criar issue a partir do botão
  • JQL: buscar issues similares antes de criar duplicata

3. Access control (crítico)

  • Retrieval usa permissão do usuário do Slack, não do bot
  • Mapeamento Slack user → Confluence permissions
  • Teste: usuário sem acesso a espaço restrito não vê conteúdo dele

Security checklist (o perfil da função pede explicitamente)

  • Assinatura de webhook verificada
  • Secrets em Secret Manager
  • Token nunca logado
  • Conteúdo do Slack e do Jira tratado como untrusted (prompt injection)
  • Teste: alguém escreve "ignore suas instruções" no Slack → bot não obedece
  • Escopo mínimo em ambas as integrações
  • Audit log de quem perguntou o quê

Entregável

p6_integrations/
├── slack/
│   ├── app.py
│   ├── verify.py           # assinatura
│   └── blocks.py           # Block Kit
├── atlassian/
│   ├── confluence.py       # ingestão
│   └── jira.py             # criação de issue
├── access_control.py
├── tests/
│   ├── test_security.py    # injection, assinatura, escopo
│   └── test_permissions.py
└── docs/
    ├── runbook.md          # como operar
    └── security_review.md

Definition of Done

  • Bot respondendo no Slack de verdade
  • Confluence ingerido e pesquisável
  • Criação de ticket no Jira funcionando
  • Access control testado (usuário sem permissão não vê)
  • Prompt injection via Slack testado e bloqueado
  • Runbook escrito
  • Alguém além de você usou pelo menos uma vez
