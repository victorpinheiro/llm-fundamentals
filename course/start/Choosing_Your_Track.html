Escolhendo Sua Trilha

O que é comum às duas

Os conceitos. Tokens, janela de contexto, alucinação, RAG, avaliação,
modos de falha de agentes, injeção de prompt — nada disso muda de acordo
com o provedor. Os módulos 1 a 11 são idênticos para todo mundo.

O que muda é como você implementa: qual SDK, qual autenticação,
qual runtime de deploy, quais serviços gerenciados existem.

Trilha A — OpenAI e Anthropic

Estude esta trilha se:
- Quer entender os mecanismos sem camadas de abstração
- Trabalha em ambiente multi-nuvem ou sem nuvem definida
- Prefere montar a arquitetura peça por peça
- Quer o caminho mais direto para começar hoje

O que você usa:
- SDKs diretos dos provedores
- Chave de API para autenticação
- Banco vetorial próprio (pgvector, Qdrant, Weaviate)
- Orquestração de agentes com código próprio ou LangGraph
- Deploy onde você quiser

Vantagem pedagógica: você vê tudo. Não há serviço gerenciado
escondendo o funcionamento, o que torna o aprendizado mais profundo.

Desvantagem: você constrói mais coisas do zero, incluindo partes que
uma plataforma gerenciada daria pronta.

Ver Trilha A — OpenAI e Anthropic.

Trilha B — Google Cloud (GEAP)

Estude esta trilha se:
- Sua organização já usa Google Cloud
- Precisa de governança corporativa (residência de dados, chaves próprias)
- Quer runtime gerenciado para agentes
- Vagas do seu mercado pedem esse stack explicitamente

O que você usa:
- Gemini Enterprise Agent Platform (a plataforma antes chamada Vertex AI)
- Autenticação por conta de serviço, ADC e IAM — nunca chave de API
- Agent Development Kit (ADK) para agentes
- Agent Runtime para deploy gerenciado
- Serviços gerenciados de busca e RAG

Vantagem: o caminho de produção corporativa é muito mais curto.
Governança, identidade e conformidade vêm da plataforma.

Desvantagem: mais abstração, mais nomes proprietários, e uma
plataforma que passou por renomeação recente — ver Aviso de Volatilidade.

Ver Trilha B — Plataforma Corporativa do Google Cloud.

Trilha C — Provedores Gratuitos

Estude esta trilha se:
- Nao quer gastar nada — nenhum cartao de credito necessario
- Esta aprendendo do zero e quer comecar imediatamente
- Quer experimentar modelos open-source (Llama, Qwen, Gemma)
- Precisa de privacidade total com execucao local (Ollama)

O que voce usa:
- Google Gemini via AI Studio (gratuito, 1.500 req/dia)
- Groq (gratuito, API compativel com OpenAI, modelos Llama)
- Ollama (local, ilimitado, modelos open-source)
- Chave de API para Gemini e Groq, sem chave para Ollama

Vantagem: custo zero, começo em minutos, tres provedores com fallback entre eles. Ollama permite uso totalmente offline.

Desvantagem: limites de requisicoes por minuto nos provedores cloud, modelos open-source podem ser inferiores aos pagos em tarefas complexas, sem governanca corporativa.

Ver Trilha C — Provedores Gratuitos.

Fazendo mais de uma trilha

Recomendado se voce tem tempo. Algumas combinacoes que funcionam:

  • Trilha C primeiro, depois A: comece sem gastar nada, aprenda os conceitos, depois migre para provedores pagos quando precisar de qualidade maxima. A migracao e simples porque os conceitos sao os mesmos.
  • Trilha C + A em paralelo: use Trilha C para desenvolvimento e testes (custo zero), e Trilha A para comparar qualidade nos projetos de avaliacao.
  • Trilha A nos modulos 1 a 5, Trilha B a partir do 6: aprende os mecanismos sem abstracao, depois reconhece o que a plataforma abstrai.

Saber posicionar mais de uma plataforma e uma competencia que aparece em entrevista.

Nao escolha por hype

Escolha pelo seu contexto. Se nao quer gastar nada, comece pela Trilha C. Se sabe onde vai trabalhar, escolha a trilha desse stack. Se nao sabe, a Trilha C e a melhor porta de entrada — os conceitos transferem e o custo de migrar depois e baixo.
