Como Usar Este Curso

Ritmo

O curso é autoguiado. Não há prazo. A sugestão de 20–26 semanas assume
12–18h por semana, mas quem tem mais tempo pode comprimir e quem tem menos
pode estender sem perda.

O que não funciona é pular projetos. O conteúdo conceitual sozinho não
produz competência — a competência vem de construir, medir e errar.

Estrutura de um módulo

Cada módulo em 01_Modules/ tem:

Seção O que é
Objetivo O que você saberá fazer ao final
Por que importa O contexto prático do tema
Conceitos O conteúdo em si
Trilha A / Trilha B Especificidades de implementação
Projeto O que construir
Autoavaliação Perguntas para checar se aprendeu
Erros comuns O que costuma dar errado

Estrutura de um projeto

Cada projeto em 04_Projects/ tem:

  • Pré-condição — o que precisa estar pronto antes
  • Cenário — o problema a resolver
  • Requisitos — o que o sistema precisa fazer
  • Entregável — a estrutura de arquivos esperada
  • Definition of Done — critérios objetivos de conclusão

Os projetos são cumulativos. O P7 usa ferramentas construídas no P6, que
usa o RAG do P5. Fazer fora de ordem gera retrabalho.

Como estudar cada tema

Um ciclo que funciona bem:

  1. Leia o módulo (1–2h) — entenda os conceitos e os modos de falha
  2. Leia a documentação oficial da sua trilha (2–3h) — não pule
  3. Construa o projeto (6–10h) — errando de verdade
  4. Meça (1–2h) — números, não impressões
  5. Escreva o que aprendeu (30min) — em 06_Progress/

O passo 5 parece supérfluo e não é. Escrever força a articular o que você
entendeu de fato, e quem entrega IA precisa explicar decisões técnicas em texto.

Sobre a documentação oficial

Este curso aponta para documentação em vez de reproduzi-la. Isso é
deliberado:

  • APIs de IA mudam a cada poucos meses
  • Um curso que embute assinaturas de função envelhece mal
  • Saber ler documentação é parte da competência

Sempre que houver conflito entre este material e a documentação oficial,
a documentação oficial vence. Ver Aviso de Volatilidade.

Autoavaliação honesta

Ao final de cada módulo há perguntas. Responda por escrito, sem consultar.
Se não conseguir responder, volte — não avance.

O sinal de que você aprendeu não é ter terminado o projeto. É conseguir
explicar por que tomou cada decisão e o que teria acontecido se tivesse
escolhido diferente.
