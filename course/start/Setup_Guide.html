Guia de Setup

Comum às duas trilhas

Ambiente Python

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install pydantic python-dotenv pytest

Use Python 3.11 ou superior. Versões anteriores funcionam, mas alguns
SDKs já exigem 3.10+.

Segredos

Nunca comite credenciais. Crie .env e adicione ao .gitignore
antes de colocar qualquer chave nele.

echo ".env" >> .gitignore
echo ".venv/" >> .gitignore

Banco de dados (a partir do Módulo 6)

Postgres com a extensão de vetores, via Docker:

docker run -d --name course-pg \
  -e POSTGRES_PASSWORD=localdev \
  -p 5432:5432 \
  pgvector/pgvector:pg16

Ferramentas de avaliação (Módulo 4)

pip install deepeval ragas

Trilha A — setup específico

pip install openai anthropic

Crie contas nos dois provedores e gere chaves de API.
Ambos oferecem crédito inicial para testes.

# .env
OPENAI_API_KEY=...
ANTHROPIC_API_KEY=...

Configure limite de gasto no painel de cada provedor antes de começar.

Trilha B — setup específico

Projeto na nuvem

  1. Crie um projeto no Google Cloud (ou peça acesso a um de testes)
  2. Habilite a API da plataforma de IA
  3. Configure faturamento e defina um orçamento com alerta

Autenticação

Não use chave de API. Use credenciais padrão da aplicação:

gcloud auth application-default login

Em produção, use conta de serviço ou identidade de agente
(ver Trilha B — Plataforma Corporativa do Google Cloud).

SDK

pip install google-cloud-aiplatform
pip install google-adk          # a partir do Módulo 8

⚠️ Confirme o nome e a versão atual dos pacotes na documentação oficial.
Ver Aviso de Volatilidade.

Obsidian

Este curso é um vault Obsidian, mas funciona como markdown puro em
qualquer editor. Se usar Obsidian, os links entre colchetes duplos viram navegação clicável.

Plugins úteis (opcionais, todos gratuitos):
- Calendar — visualizar progresso
- Dataview — consultar suas próprias notas

Verificação

Antes de seguir para o Módulo 1, confirme:

  • Ambiente virtual ativo
  • .env no .gitignore
  • Chamada de teste funcionando no provedor da sua trilha
  • Alerta de orçamento configurado
  • pytest roda sem erro num teste vazio
  • Repositório git inicializado para seus projetos
