Trilha C — Provedores Gratuitos

Custo zero. Nenhum cartao de credito necessario.

Filosofia desta trilha

Aprender todos os conceitos do curso sem gastar nada. Voce usa tres provedores gratuitos — dois na nuvem e um local — que juntos cobrem todos os projetos do curso, da primeira chamada de API ate agentes com ferramentas.

Os conceitos sao identicos aos das Trilhas A e B. O que muda e o SDK, a autenticacao e os limites de uso.

Os tres provedores

Provedor Tipo Modelos principais Limites gratuitos
Google Gemini (AI Studio) Cloud gratuito gemini-2.0-flash, gemini-2.0-flash-lite 1.500 req/dia, 15 RPM, 1M TPM
Groq Cloud gratuito llama-3.3-70b-versatile, llama-3.1-8b-instant 30 RPM, 14.400 req/dia
Ollama Local gratuito llama3.2, llama3.1, qwen2.5, gemma Ilimitado (depende do hardware)

Recomendacao: comece com Gemini como provedor principal e Groq como alternativa. Use Ollama quando quiser privacidade total ou experimentar sem conexao.

Setup

pip install google-genai openai python-dotenv

O pacote openai serve para Groq e Ollama — ambos usam API compativel com OpenAI. Nao precisa do pacote groq (embora exista), porque o SDK OpenAI conecta direto alterando a base_url.

Credenciais

# .env
GEMINI_API_KEY=...sua-chave-aqui...
GROQ_API_KEY=gsk_...sua-chave-aqui...

Obtenha as chaves gratuitamente em:

  • Gemini: aistudio.google.com/apikey
  • Groq: console.groq.com/keys
  • Ollama: sem chave — instale de ollama.com e execute ollama pull llama3.2

Primeira chamada

Gemini (AI Studio)

# hello_gemini.py
import os
from dotenv import load_dotenv
from google import genai

load_dotenv()

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

response = client.models.generate_content(
    model="gemini-2.0-flash",
    contents="Say 'Hello, world!' and explain in one sentence what an LLM is.",
)

print(response.text)
print(f"\nTokens — input: {response.usage_metadata.prompt_token_count}, "
      f"output: {response.usage_metadata.candidates_token_count}")

Groq (OpenAI-compatible)

# hello_groq.py
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.getenv("GROQ_API_KEY"),
    base_url="https://api.groq.com/openai/v1",
)

response = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Say 'Hello, world!' and explain in one sentence what an LLM is."},
    ],
    temperature=0,
)

print(response.choices[0].message.content)
print(f"\nTokens used: {response.usage.total_tokens}")

Ollama (local, OpenAI-compatible)

# hello_ollama.py
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama",  # required by SDK but not validated
)

response = client.chat.completions.create(
    model="llama3.2",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Say 'Hello, world!' and explain in one sentence what an LLM is."},
    ],
    temperature=0,
)

print(response.choices[0].message.content)

Saida estruturada

Os tres provedores suportam saida estruturada:

  • Gemini: suporte nativo via response_schema no SDK google-genai
  • Groq: suporte via response_format (mesmo formato da OpenAI)
  • Ollama: suporte via response_format (mesmo formato da OpenAI)

Exemplos completos no P1 — Primeira Integracao com Saida Estruturada.

Uso de ferramentas (function calling)

Os tres suportam chamada de funcao:

  • Gemini: nativo, via parametro tools no SDK
  • Groq: compativel com o formato OpenAI de tool use
  • Ollama: compativel com o formato OpenAI de tool use (modelos que suportam: llama3.1+, qwen2.5+)

O fluxo e o mesmo das Trilhas A e B:

  1. Declare as ferramentas disponiveis
  2. O modelo indica qual quer chamar
  3. Voce executa e devolve o resultado
  4. O modelo continua

Limites e estrategias

Provedores gratuitos tem limites de requisicoes por minuto (RPM) e por dia. Estrategias para lidar com isso:

  • Fallback entre provedores: se Gemini atingir o limite, tente Groq. Se Groq atingir, use Ollama local.
  • Rate limiting no codigo: adicione time.sleep() entre chamadas em loops de avaliacao.
  • Cache de respostas: salve respostas em arquivo para nao repetir chamadas identicas.
  • Ollama como fallback ilimitado: modelos menores locais nao tem limite e servem bem para desenvolvimento e testes.

Camadas de modelo

Camada Gemini Groq Ollama
Maior gemini-2.0-flash llama-3.3-70b-versatile llama3.1:70b (requer 40GB+ RAM)
Intermediaria gemini-2.0-flash llama-3.1-8b-instant llama3.2 (3B)
Menor gemini-2.0-flash-lite llama-3.1-8b-instant qwen2.5:1.5b, gemma:2b

Vantagens e limitacoes

Vantagens: custo zero, sem cartao de credito, começo imediato, tres provedores com fallback entre eles, Ollama para privacidade e uso offline.

Limitacoes: limites de RPM e requisicoes diarias nos provedores cloud, modelos locais exigem hardware razoavel (8GB+ RAM para modelos pequenos), qualidade de modelos open-source pode ser inferior aos modelos pagos em tarefas complexas.
