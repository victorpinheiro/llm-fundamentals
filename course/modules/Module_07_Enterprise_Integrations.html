Módulo 7 — Integrações Corporativas

Projeto: P6 — Integração Corporativa · Conceito: Referência — Integrações

Objetivo

Conectar um sistema de IA às ferramentas que as pessoas realmente usam,
com autenticação correta, permissões respeitadas e tratamento de conteúdo
externo como não confiável.

Por que importa

Um sistema de IA que exige abrir outra aba não é adotado. A adoção vem
de encontrar as pessoas onde elas já estão — na ferramenta de mensagens,
no rastreador de tarefas, na base de conhecimento.

Este módulo também é o que transforma os projetos anteriores em algo
que alguém usa de verdade. Até aqui você construiu peças; agora elas
ganham uma porta de entrada.

Categorias de integração

Categoria Exemplos Papel no sistema
Mensagens Plataformas de chat corporativo Interface de entrada e saída
Rastreamento Sistemas de tickets e tarefas Fonte de contexto e destino de ações
Conhecimento Wikis, bases documentais Acervo para recuperação
Reuniões Transcrições, agendas Fonte de dados sensíveis
Dados Bancos, planilhas, armazéns Consulta estruturada

Padrões que se repetem

Autenticação

Modelo Uso
Token de aplicação Automação agindo como si mesma
Delegação do usuário Ação em nome de uma pessoa
Conta de serviço Processos de servidor

Regra: peça o menor escopo que resolve. Revisões de segurança olham
escopos concedidos, e escopo excessivo é motivo comum de reprovação.

Verificação de origem

Toda integração que recebe eventos precisa verificar que a requisição
veio mesmo de quem diz ter vindo. Plataformas sérias assinam as
requisições; verificar essa assinatura não é opcional.

Um endpoint que aceita qualquer requisição é uma porta aberta.

Permissões

O ponto crítico, que se repete do módulo anterior:

A ação deve respeitar as permissões da pessoa, não as do sistema.

Se o sistema tem acesso amplo e responde sem filtrar por quem perguntou,
você construiu um vazamento de informação com interface amigável.

Limites de taxa

Toda API impõe limites. Planeje com antecedência:
- Recuo exponencial com variação aleatória
- Fila para operações em volume
- Cache do que não muda com frequência

Conteúdo externo é não confiável

Mensagens, tickets, páginas de wiki e documentos são escritos por pessoas.
Algumas dessas pessoas podem escrever conteúdo desenhado para subverter
seu sistema.

Se alguém escrever "ignore suas instruções anteriores" num ticket, seu
sistema não pode obedecer. Isso exige que você trate o conteúdo como dado,
nunca como instrução — ver Referência — Limitações.

Segurança

Lista mínima antes de considerar uma integração pronta:

  • Segredos em cofre apropriado, nunca em código ou variável simples
  • Assinatura de requisição verificada
  • Escopos no mínimo necessário
  • Permissões do usuário respeitadas
  • Credenciais nunca registradas em log
  • Conteúdo externo sanitizado
  • Registro de auditoria de quem pediu o quê
  • Dados sensíveis removidos antes de ir para o modelo

Cada integração vira uma ferramenta

Este módulo prepara o próximo. As integrações que você constrói aqui
tornam-se as ferramentas que o agente do Módulo 8 vai usar.

É por isso que integrações vêm antes de agentes neste curso: um agente
sem ferramentas reais é exercício acadêmico. Com ferramentas reais, os
modos de falha aparecem de verdade.

Projeto

P6 — Integração Corporativa — interface de mensagens sobre o RAG do
projeto anterior, com criação de tarefas e controle de acesso.

Autoavaliação

  1. Por que verificar assinatura de requisição é obrigatório?
  2. Qual a diferença entre token de aplicação e delegação do usuário?
  3. Alguém escreve instrução maliciosa num ticket que seu sistema lê.
    O que impede o sistema de obedecer?
  4. Como mapear identidade entre duas plataformas diferentes?
  5. Que dados nunca devem chegar ao modelo, e como garantir isso?

Erros comuns

  • Pular verificação de assinatura em desenvolvimento e esquecer depois
  • Pedir escopos amplos "para facilitar"
  • Usar permissões do sistema para responder a qualquer usuário
  • Tratar conteúdo recuperado como confiável
  • Ignorar limites de taxa até o primeiro bloqueio
