P5 — Sistema de Recuperação

Módulo: Módulo 6 — Geração Aumentada por Recuperação · Tempo: 20–26h · Degrau 2

Pré-condição

Documente por escrito antes de codificar:

  1. Precisa de conhecimento externo ao modelo? Por quê?
  2. O acervo cabe na janela de contexto? Calcule.
  3. Citação de fonte é obrigatória?
  4. A plataforma já oferece recuperação gerenciada? Se sim, por que
    construir do zero?

Sem esse documento, o projeto está incompleto.

Cenário

Base de documentação de processos e políticas.
Perguntas do tipo: "qual o procedimento para X?"

Use documentos públicos ou sintéticos. Não use material interno
confidencial de nenhuma organização num projeto de aprendizado.

Pipeline

Documentos
  → decisão de fragmentação (justificada)
  → embeddings
  → índice com metadados

Pergunta
  → busca vetorial + busca por termo
  → fusão de postos recíprocos
  → filtro de permissão
  → prompt com ancoragem
  → resposta com citação

Passo 2 — Implemente a fragmentação (chunking)

Fragmentação é cortar documentos em pedaços menores para indexação. O tamanho do chunk afeta diretamente a qualidade:

  • 500 chars — alta precisão, mas pode cortar no meio de uma ideia
  • 1000 chars — bom equilíbrio para a maioria dos casos
  • 2000 chars — preserva mais contexto, mas reduz precisão de busca

Crie ingestao.py:

"""ingestao.py — carrega documentos, fragmenta e indexa."""
import os, hashlib
from pathlib import Path

# Opção 1: LangChain text splitters (pip install langchain-text-splitters)
from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200,        # sobreposição para não cortar ideias
    separators=["\n## ", "\n### ", "\n\n", "\n", ". ", " "],
)

def carregar_documentos(diretorio: str) -> list[dict]:
    """Carrega todos os .md de um diretório e fragmenta."""
    chunks = []
    for arquivo in sorted(Path(diretorio).glob("*.md")):
        texto = arquivo.read_text(encoding="utf-8")
        pedacos = splitter.split_text(texto)
        for i, pedaco in enumerate(pedacos):
            chunks.append({
                "id": hashlib.md5(f"{arquivo.name}:{i}".encode()).hexdigest(),
                "texto": pedaco,
                "metadata": {
                    "fonte": arquivo.name,
                    "chunk_index": i,
                    "total_chunks": len(pedacos),
                },
            })
    print(f"Carregados {len(chunks)} chunks de {diretorio}")
    return chunks

Passo 3 — Gere embeddings

Embeddings convertem texto em vetores numéricos para busca por similaridade.

Trilha A — OpenAI:

from openai import OpenAI

client = OpenAI()

def gerar_embeddings(textos: list[str]) -> list[list[float]]:
    """Gera embeddings para uma lista de textos."""
    resposta = client.embeddings.create(
        model="text-embedding-3-small",
        input=textos,
    )
    return [item.embedding for item in resposta.data]

Trilha B — Vertex AI:

from google import genai

client = genai.Client(vertexai=True, project="SEU_PROJETO", location="us-central1")

    """Gera embeddings com Vertex AI."""

        contents=textos,
    )

Track C — Groq

Groq does not offer an embeddings API. For embeddings, pair Groq (used for generation) with a free embedding source such as Gemini text-embedding-004 above, or Ollama nomic-embed-text below. Use Groq only for the generation step in the RAG pipeline.

Track C — Ollama

Ollama runs locally and offers embeddings via the nomic-embed-text model. Pull the model first: ollama pull nomic-embed-text

import ollama

def generate_embeddings(texts: list[str]) -> list[list[float]]:
    """Generate embeddings with Ollama nomic-embed-text (local, free)."""
    embeddings = []
    for text in texts:
        response = ollama.embeddings(model="nomic-embed-text", prompt=text)
        embeddings.append(response["embedding"])
    return embeddings

Note: Ollama processes one text at a time. For large corpora, this is slower than batched APIs but has zero cost and no rate limits.

Passo 4 — Configure o vector store com ChromaDB

ChromaDB é a opção mais simples para aprendizado: instale com pip install chromadb, sem servidor, sem configuração. Os dados ficam num diretório local.

"""Continuação de ingestao.py — indexação no ChromaDB."""
import chromadb

# Cria (ou abre) a coleção local
chroma_client = chromadb.PersistentClient(path="./chroma_db")
collection = chroma_client.get_or_create_collection(
    name="documentos",
    metadata={"hnsw:space": "cosine"},   # distância cosseno
)

def indexar(chunks: list[dict]):
    """Gera embeddings e adiciona ao ChromaDB."""
    textos = [c["texto"] for c in chunks]
    ids = [c["id"] for c in chunks]
    metadatas = [c["metadata"] for c in chunks]

    # Gera embeddings em lotes de 100
    embeddings = []
    for i in range(0, len(textos), 100):
        lote = textos[i:i+100]
        embeddings.extend(gerar_embeddings(lote))

    collection.add(
        ids=ids,
        embeddings=embeddings,
        documents=textos,
        metadatas=metadatas,
    )
    print(f"Indexados {len(chunks)} chunks no ChromaDB")

if __name__ == "__main__":
    chunks = carregar_documentos("corpus")
    indexar(chunks)

Passo 5 — Implemente busca híbrida

Busca vetorial é boa para similaridade semântica, mas perde termos exatos (siglas, códigos, nomes). BM25 complementa com busca por palavras-chave. A fusão de postos recíprocos (Reciprocal Rank Fusion — RRF) combina os dois rankings.

Algoritmo RRF: para cada documento que aparece em qualquer ranking, some 1 / (k + posição) de cada ranking onde ele aparece. O k é uma constante (tipicamente 60) que controla o peso de posições altas. Ordene pelo score combinado.

"""recuperador.py — busca híbrida: vetorial + BM25 com RRF."""
import chromadb
from rank_bm25 import BM25Okapi    # pip install rank_bm25

chroma_client = chromadb.PersistentClient(path="./chroma_db")
collection = chroma_client.get_collection("documentos")

# Carrega todos os documentos para o BM25
todos = collection.get(include=["documents", "metadatas"])
corpus_texto = todos["documents"]
corpus_ids = todos["ids"]
corpus_meta = todos["metadatas"]

# Tokenização simples para BM25
corpus_tokenizado = [doc.lower().split() for doc in corpus_texto]
bm25 = BM25Okapi(corpus_tokenizado)

def busca_vetorial(pergunta: str, top_k: int = 10) -> list[dict]:
    """Busca por similaridade semântica no ChromaDB."""
    from ingestao import gerar_embeddings
    emb = gerar_embeddings([pergunta])[0]
    resultados = collection.query(query_embeddings=[emb], n_results=top_k,
                                  include=["documents", "metadatas", "distances"])
    return [
        {"id": resultados["ids"][0][i], "texto": resultados["documents"][0][i],
         "metadata": resultados["metadatas"][0][i], "score": 1 - resultados["distances"][0][i]}
        for i in range(len(resultados["ids"][0]))
    ]

def busca_bm25(pergunta: str, top_k: int = 10) -> list[dict]:
    """Busca por palavras-chave com BM25."""
    tokens = pergunta.lower().split()
    scores = bm25.get_scores(tokens)
    indices = sorted(range(len(scores)), key=lambda i: scores[i], reverse=True)[:top_k]
    return [
        {"id": corpus_ids[i], "texto": corpus_texto[i],
         "metadata": corpus_meta[i], "score": float(scores[i])}
        for i in indices if scores[i] > 0
    ]

def fusao_rrf(resultados_vetorial: list, resultados_bm25: list, k: int = 60) -> list[dict]:
    """Reciprocal Rank Fusion — combina dois rankings."""
    scores = {}
    docs = {}
    for ranking in [resultados_vetorial, resultados_bm25]:
        for posicao, doc in enumerate(ranking):
            doc_id = doc["id"]
            scores[doc_id] = scores.get(doc_id, 0) + 1.0 / (k + posicao + 1)
            docs[doc_id] = doc
    ordenados = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    return [docs[doc_id] for doc_id, _ in ordenados]

def recuperar(pergunta: str, top_k: int = 5) -> list[dict]:
    """Busca híbrida completa: vetorial + BM25 + RRF."""
    vetorial = busca_vetorial(pergunta, top_k=10)
    keyword = busca_bm25(pergunta, top_k=10)
    combinados = fusao_rrf(vetorial, keyword)
    return combinados[:top_k]

Passo 6 — Construa o pipeline RAG

Crie rag.py que conecta recuperação à geração com ancoragem e citação:

"""rag.py — pipeline completo de RAG com citação de fontes."""
from recuperador import recuperar

# === Trilha A ===
from openai import OpenAI
client = OpenAI()
MODELO = "gpt-4o-mini"

# === Trilha B (descomente) ===

# client = genai.Client(vertexai=True, project="SEU_PROJETO", location="us-central1")
# MODELO = "gemini-2.0-flash"

PROMPT_SISTEMA = """\
Você é um assistente que responde perguntas com base EXCLUSIVAMENTE nos trechos
fornecidos abaixo. Regras:

1. Use APENAS informações presentes nos trechos. Não invente.
2. Cite a fonte entre colchetes: [nome_do_arquivo.md]
3. Se nenhum trecho contiver a resposta, diga: "Não encontrei essa informação
   nos documentos disponíveis."
4. Se a resposta estiver parcialmente nos trechos, responda o que puder e
   indique o que não encontrou.
"""

def montar_contexto(chunks: list[dict]) -> str:
    """Formata os chunks recuperados como contexto para o prompt."""
    blocos = []
    for i, chunk in enumerate(chunks, 1):
        fonte = chunk["metadata"]["fonte"]
        blocos.append(f"[Trecho {i} — {fonte}]\n{chunk['texto']}")
    return "\n\n---\n\n".join(blocos)

def perguntar(pergunta: str, top_k: int = 5) -> dict:
    """Pipeline completo: recupera, monta prompt, gera resposta."""
    # 1. Recuperar chunks relevantes
    chunks = recuperar(pergunta, top_k=top_k)

    if not chunks:
        return {
            "resposta": "Não encontrei essa informação nos documentos disponíveis.",
            "fontes": [],
            "chunks_usados": 0,
        }

    contexto = montar_contexto(chunks)
    prompt_usuario = f"Contexto:\n{contexto}\n\n---\nPergunta: {pergunta}"

    # 3. Gerar resposta (Trilha A)
    resp = client.chat.completions.create(
        model=MODELO,
        messages=[
            {"role": "system", "content": PROMPT_SISTEMA},
            {"role": "user", "content": prompt_usuario},

    resposta = resp.choices[0].message.content

Passo 7 — Teste os modos de falha

Cada modo de falha deve virar um teste automatizado. Crie testes/test_modos_falha.py:

"""test_modos_falha.py — testa os 6 modos de falha do RAG."""
from rag import perguntar
from recuperador import recuperar

# 1. Descasamento semântico — sinônimo encontra o documento?
def test_descasamento_semantico():
    """O documento fala 'instalar', a pergunta usa 'configurar o setup'."""
    resultado = recuperar("como configurar o setup inicial")
    fontes = [c["metadata"]["fonte"] for c in resultado]
    # Deve encontrar o documento de instalação mesmo com palavras diferentes
    assert any("instal" in f.lower() for f in fontes), \
        f"Busca por sinônimo falhou. Fontes encontradas: {fontes}"

# 2. Fragmentação — resposta que cruza dois chunks
def test_resposta_cruza_chunks():
    """Pergunta cuja resposta está dividida entre dois trechos consecutivos."""
    resultado = perguntar("Explique o processo completo de instalação e configuração")
    # A resposta deve mencionar conteúdo de mais de um trecho
    assert resultado["chunks_usados"] >= 2, \
        "Esperava usar pelo menos 2 chunks para resposta completa"

# 3. Corte curto (top-k insuficiente)
def test_corte_curto():
    """Aumentar top_k melhora a resposta?"""
    r_curto = perguntar("Descreva todas as opções de configuração", top_k=2)
    r_longo = perguntar("Descreva todas as opções de configuração", top_k=8)
    # A resposta com mais chunks deve ser mais completa (mais caracteres)
    assert len(r_longo["resposta"]) >= len(r_curto["resposta"]) * 0.8, \
        "top_k maior não melhorou a resposta — investigue a recuperação"

def test_contaminacao():

  • Contaminação — trecho irrelevante degrada a resposta?
  • Alucinação apesar do contexto — inventa quando não sabe?
