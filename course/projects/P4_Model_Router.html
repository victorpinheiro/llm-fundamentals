P4 — Roteador de Modelos

Módulo: Módulo 4 — Seleção de Modelo e Custo · Tempo: 10–14h · Degrau 1

Objetivo

Reduzir custo com roteamento por complexidade — ou concluir com dados
que não compensa.

Arquitetura

entrada → classificador (modelo mais barato)
        → simples  → modelo pequeno
        → média    → modelo intermediário
        → complexa → modelo grande

Passo a passo

Passo 1 — Defina as camadas de modelo

Escolha três modelos com faixas de custo distintas. Exemplos por trilha:

CamadaTrilha A (OpenAI + Anthropic)Trilha B (Google Cloud)
Pequeno (barato)gpt-4o-minigemini-2.0-flash-lite
Intermediárioclaude-3-5-haikugemini-2.0-flash
Grande (caro)claude-sonnet-4 ou gpt-4ogemini-2.5-pro

Anote o custo por milhão de tokens (input e output) de cada um. Você vai precisar disso no Passo 4.

Passo 2 — Construa o classificador de complexidade

O classificador usa o modelo mais barato para decidir qual camada deve responder. Crie classificador_complexidade.py:

"""classificador_complexidade.py — classifica a complexidade de uma pergunta."""
import os
from openai import OpenAI          # Trilha A
# from google import genai          # Trilha B — descomente e ajuste

client = OpenAI()  # usa OPENAI_API_KEY do ambiente

PROMPT_CLASSIFICADOR = """\
Você é um roteador de complexidade. Dada a pergunta do usuário, classifique-a
em exatamente uma categoria:

- SIMPLES: pergunta factual curta, tradução direta, formatação.
- MEDIA: resumo de texto médio, comparação entre dois itens, explicação conceitual.
- COMPLEXA: análise multi-etapa, raciocínio lógico, geração longa ou criativa.

Responda APENAS com uma palavra: SIMPLES, MEDIA ou COMPLEXA.
"""

def classificar(pergunta: str) -> str:
    """Retorna 'SIMPLES', 'MEDIA' ou 'COMPLEXA'."""
    resposta = client.chat.completions.create(
        model="gpt-4o-mini",           # modelo mais barato
        messages=[
            {"role": "system", "content": PROMPT_CLASSIFICADOR},
            {"role": "user", "content": pergunta},
        ],
        temperature=0,
        max_tokens=10,
    )
    categoria = resposta.choices[0].message.content.strip().upper()
    if categoria not in ("SIMPLES", "MEDIA", "COMPLEXA"):
        return "COMPLEXA"              # fallback seguro
    return categoria

Passo 3 — Construa o roteador

O roteador conecta o classificador aos modelos. Crie roteador.py:

"""roteador.py — roteia perguntas para o modelo adequado à complexidade."""
import time
from classificador_complexidade import classificar

# === Trilha A ===
from openai import OpenAI
import anthropic

openai_client = OpenAI()
anthropic_client = anthropic.Anthropic()

MODELOS = {
    "SIMPLES":  {"provider": "openai",    "model": "gpt-4o-mini"},
    "MEDIA":    {"provider": "anthropic",  "model": "claude-3-5-haiku-20241022"},
    "COMPLEXA": {"provider": "anthropic",  "model": "claude-sonnet-4-20250514"},
}

# === Trilha B (descomente e ajuste) ===
# from google import genai
# vertex_client = genai.Client(vertexai=True, project="SEU_PROJETO", location="us-central1")
# MODELOS = {
#     "SIMPLES":  {"provider": "vertex", "model": "gemini-2.0-flash-lite"},
#     "MEDIA":    {"provider": "vertex", "model": "gemini-2.0-flash"},
#     "COMPLEXA": {"provider": "vertex", "model": "gemini-2.5-pro"},
# }

# Custo por milhão de tokens (input / output) — preencha com valores atuais
CUSTO_POR_MILHAO = {
    "gpt-4o-mini":                  {"input": 0.15,  "output": 0.60},
    "claude-3-5-haiku-20241022":    {"input": 0.80,  "output": 4.00},
    "claude-sonnet-4-20250514":     {"input": 3.00,  "output": 15.00},
}

def chamar_modelo(pergunta: str, provider: str, model: str) -> dict:
    """Chama o modelo e retorna resposta + metadados."""
    if provider == "openai":
        resp = openai_client.chat.completions.create(
            model=model,
            messages=[{"role": "user", "content": pergunta}],
        )
        return {
            "texto": resp.choices[0].message.content,
            "tokens_input": resp.usage.prompt_tokens,
            "tokens_output": resp.usage.completion_tokens,
        }
    elif provider == "anthropic":
        resp = anthropic_client.messages.create(
            model=model,
            max_tokens=1024,
            messages=[{"role": "user", "content": pergunta}],
        )
        return {
            "texto": resp.content[0].text,
            "tokens_input": resp.usage.input_tokens,
            "tokens_output": resp.usage.output_tokens,
        }
    # Trilha B:
    # elif provider == "vertex":
    #     resp = vertex_client.models.generate_content(model=model, contents=pergunta)
    #     return {
    #         "texto": resp.text,
    #         "tokens_input": resp.usage_metadata.prompt_token_count,
    #         "tokens_output": resp.usage_metadata.candidates_token_count,
    #     }

def calcular_custo(model: str, tokens_input: int, tokens_output: int) -> float:
    tabela = CUSTO_POR_MILHAO.get(model, {"input": 0, "output": 0})
    return (tokens_input * tabela["input"] + tokens_output * tabela["output"]) / 1_000_000

def rotear(pergunta: str) -> dict:
    """Classifica, roteia e retorna resposta com metadados completos."""
    complexidade = classificar(pergunta)
    config = MODELOS[complexidade]

    inicio = time.time()
    resultado = chamar_modelo(pergunta, config["provider"], config["model"])
    latencia = time.time() - inicio

    custo = calcular_custo(
        config["model"], resultado["tokens_input"], resultado["tokens_output"]
    )

    return {
        "pergunta": pergunta,
        "complexidade": complexidade,
        "modelo": config["model"],
        "resposta": resultado["texto"],
        "tokens_input": resultado["tokens_input"],
        "tokens_output": resultado["tokens_output"],
        "custo_usd": custo,
        "latencia_s": round(latencia, 3),
    }

if __name__ == "__main__":
    r = rotear("Qual a capital da França?")
    print(f"[{r['complexidade']}] {r['modelo']} — ${r['custo_usd']:.6f} — {r['latencia_s']}s")
    print(r["resposta"][:200])

Passo 4 — Construa o script de comparação

Crie comparar.py para rodar os 50 casos do P2 em três modos e coletar métricas:

"""comparar.py — compara sempre-grande vs sempre-pequeno vs roteador."""
import json, statistics
from roteador import rotear, chamar_modelo, calcular_custo, MODELOS
import time

# Carregue os 50 casos de teste do P2
with open("../p2_prompt/casos_teste.json") as f:
    casos = json.load(f)

def rodar_modo(nome: str, model_override: str | None = None):
    """Roda todos os casos num modo e coleta métricas."""
    resultados = []
    for caso in casos:
        pergunta = caso["input"]
        inicio = time.time()

        if model_override:
            # Modo fixo: sempre o mesmo modelo
            config = MODELOS[model_override]
            resp = chamar_modelo(pergunta, config["provider"], config["model"])
            custo = calcular_custo(config["model"], resp["tokens_input"], resp["tokens_output"])
            modelo_usado = config["model"]
        else:
            # Modo roteador
            r = rotear(pergunta)
            resp = {"texto": r["resposta"], "tokens_input": r["tokens_input"],
                    "tokens_output": r["tokens_output"]}
            custo = r["custo_usd"]
            modelo_usado = r["modelo"]

        latencia = time.time() - inicio
        resultados.append({
            "custo": custo,
            "latencia": latencia,
            "modelo": modelo_usado,
            # Adicione aqui sua métrica de qualidade (ex: score do avaliador do P3)
        })

    custos = [r["custo"] for r in resultados]
    latencias = [r["latencia"] for r in resultados]
    return {
        "modo": nome,
        "custo_total": sum(custos),
        "custo_medio": statistics.mean(custos),
        "latencia_p50": statistics.median(latencias),
        "latencia_p95": sorted(latencias)[int(len(latencias) * 0.95)],
        "resultados": resultados,
    }

# Rodar as três configurações
grande  = rodar_modo("Sempre grande",  "COMPLEXA")
pequeno = rodar_modo("Sempre pequeno", "SIMPLES")
router  = rodar_modo("Roteador")

# Exibir comparação
print(f"{'Modo':<20} {'Custo total':>12} {'p95 latência':>14}")
print("-" * 50)
for m in [grande, pequeno, router]:
    print(f"{m['modo']:<20} ${m['custo_total']:>10.6f} {m['latencia_p95']:>12.3f}s")

# Projeção mensal (exemplo: 10.000 chamadas/mês)
CHAMADAS_MES = 10_000
fator = CHAMADAS_MES / len(casos)
print(f"\nProjeção mensal ({CHAMADAS_MES:,} chamadas):")
for m in [grande, pequeno, router]:
    print(f"  {m['modo']}: ${m['custo_total'] * fator:.2f}/mês")

# Salvar resultados
with open("resultados/analise_custo.json", "w") as f:
    json.dump({"grande": grande, "pequeno": pequeno, "roteador": router}, f, indent=2)

Passo 5 — Teste cache de contexto

Cache de contexto é quando o provedor reutiliza prefixos repetidos de prompt para cobrar menos. Se o seu prompt de sistema é sempre o mesmo, os tokens dele podem ser cacheados automaticamente.

OpenAI — o cache é automático para prompts longos (a partir de 1024 tokens). Verifique no campo usage.prompt_tokens_details.cached_tokens da resposta. Não precisa mudar código.

Anthropic — use cache_control para marcar blocos que devem ser cacheados:

# Cache de contexto com Anthropic
resp = anthropic_client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=1024,
    system=[
        {
            "type": "text",
            "text": "Seu prompt de sistema longo aqui...",
            "cache_control": {"type": "ephemeral"},  # marca para cache
        }
    ],
    messages=[{"role": "user", "content": pergunta}],
)
# Tokens cacheados aparecem em resp.usage.cache_read_input_tokens
print(f"Tokens cacheados: {resp.usage.cache_read_input_tokens}")
print(f"Tokens criados no cache: {resp.usage.cache_creation_input_tokens}")

Vertex AI (Trilha B) — use a API de context caching para prompts muito longos (32k+ tokens):

# Cache de contexto com Vertex AI
from google import genai
from google.genai.types import Content, Part

client = genai.Client(vertexai=True, project="SEU_PROJETO", location="us-central1")

# Cria o cache (válido por 1 hora por padrão)
cache = client.caches.create(
    model="gemini-2.5-pro",
    contents=[Content(parts=[Part(text="Seu contexto longo aqui...")])],
    config={"display_name": "cache-p4", "ttl": "3600s"},
)

# Usa o cache nas chamadas seguintes
resp = client.models.generate_content(
    model="gemini-2.5-pro",
    contents="Pergunta do usuário",
    config={"cached_content": cache.name},
)

Compare o custo com e sem cache para o mesmo conjunto de perguntas e registre a diferença.

Passo 6 — Preencha a tabela, projete e conclua

Use os resultados do comparar.py para preencher a tabela de comparação abaixo. Calcule a projeção mensal com o volume real esperado (ou use 10.000 chamadas como referência). Escreva uma conclusão honesta: o roteador compensa ou não? Por quê?

Quando roteamento não vale a pena

Nem sempre um roteador compensa. Calcule antes de construir:

Exemplo com números reais: suponha 10.000 chamadas/mês, prompt médio de 500 tokens de input e 200 de output.

CenárioModeloCusto mensal
Tudo no grandeclaude-sonnet-4 ($3/M in, $15/M out)$15.00 + $3.00 = $18.00
Tudo no pequenogpt-4o-mini ($0.15/M in, $0.60/M out)$0.75 + $1.20 = $1.95
Roteador (70% pequeno, 30% grande)mix~$6.76

Se a qualidade do modelo pequeno já é suficiente para o seu caso, a economia do roteador ($6.76 vs $1.95) não justifica a complexidade extra. O roteador só compensa quando:

  • O modelo grande é significativamente melhor para os casos complexos
  • A distribuição de complexidade é mista (nem tudo simples, nem tudo complexo)
  • O classificador é preciso o bastante (erros de classificação desperdiçam dinheiro ou qualidade)
  • O volume mensal é alto o suficiente para que a diferença de custo importe

Conclusão honesta

Se o roteador não superar as linhas de base de forma relevante,
reporte isso. Situações em que não compensa:

  • Distribuição concentrada numa só categoria
  • Classificador impreciso
  • Latência adicional relevante
  • Economia marginal

Concluir "medi e não compensa" é um resultado válido e demonstra
julgamento.
