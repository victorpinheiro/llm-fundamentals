P4 — Roteador de Modelos

Módulo: Módulo 4 — Seleção de Modelo e Custo · Tempo: 10–14h · Degrau 1

Objetivo

Reduzir custo com roteamento por complexidade — ou concluir com dados
que não compensa.

Arquitetura

input → classifier (cheapest model)
      → simple   → small model
      → medium   → mid-tier model
      → complex  → large model

Passo a passo

Passo 1 — Defina as camadas de modelo

Escolha três modelos com capacidades distintas. Como todos os provedores abaixo oferecem tier gratuito, o roteamento aqui não é sobre custo monetário — é sobre limites de taxa (rate limits) e latência. Redirecionar perguntas simples para modelos menores preserva sua cota de requisições para o que realmente precisa de mais capacidade.

CamadaGemini (AI Studio)GroqOllama (local)
Pequeno (rápido)gemini-2.0-flash-litellama-3.1-8b-instantllama3.2:3b
Intermediáriogemini-2.0-flashllama-3.3-70b-versatilellama3.1:8b
Grande (detalhado)gemini-2.0-flash (prompt mais detalhado)llama-3.3-70b-versatile (com CoT)llama3.1:8b (com CoT)

Nota: como os modelos grandes gratuitos são os mesmos dos intermediários (Gemini Flash, Llama 70b), a diferença na camada "grande" vem da engenharia de prompt: prompt de sistema mais detalhado, instrução de Chain-of-Thought (CoT), ou aumento de max_tokens. Anote os limites de taxa de cada provedor — você vai precisar disso no Passo 4.

Passo 2 — Construa o classificador de complexidade

O classificador usa o modelo mais barato para decidir qual camada deve responder. Crie complexity_classifier.py:

"""complexity_classifier.py — classifies the complexity of a question."""
import os

# === Option 1: Gemini (free via AI Studio — 1,500 req/day) ===
from google import genai

gemini_client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

# === Option 2: Groq (free — 30 RPM) ===
# from groq import Groq
# groq_client = Groq()  # uses GROQ_API_KEY from environment

# === Option 3: Ollama (local — unlimited) ===
# from openai import OpenAI
# ollama_client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")

CLASSIFIER_PROMPT = """\
You are a complexity router. Given the user's question, classify it
into exactly one category:

- SIMPLE: short factual question, direct translation, formatting.
- MEDIUM: medium-length text summary, comparison between two items, conceptual explanation.
- COMPLEX: multi-step analysis, logical reasoning, long or creative generation.

Reply with ONLY one word: SIMPLE, MEDIUM or COMPLEX.
"""

def classify(question: str) -> str:
    """Returns 'SIMPLE', 'MEDIUM' or 'COMPLEX'."""
    # --- Gemini ---
    resp = gemini_client.models.generate_content(
        model="gemini-2.0-flash-lite",   # fastest model for classification
        contents=f"{CLASSIFIER_PROMPT}\n\nQuestion: {question}",
    )
    category = resp.text.strip().upper()

    # --- Groq (uncomment and comment out the Gemini block above) ---
    # resp = groq_client.chat.completions.create(
    #     model="llama-3.1-8b-instant",
    #     messages=[
    #         {"role": "system", "content": CLASSIFIER_PROMPT},
    #         {"role": "user", "content": question},
    #     ],
    #     temperature=0,
    #     max_tokens=10,
    # )
    # category = resp.choices[0].message.content.strip().upper()

    # --- Ollama (uncomment and comment out the block above) ---
    # resp = ollama_client.chat.completions.create(
    #     model="llama3.2:3b",
    #     messages=[
    #         {"role": "system", "content": CLASSIFIER_PROMPT},
    #         {"role": "user", "content": question},
    #     ],
    #     temperature=0,
    #     max_tokens=10,
    # )
    # category = resp.choices[0].message.content.strip().upper()

    if category not in ("SIMPLE", "MEDIUM", "COMPLEX"):
        return "COMPLEX"              # safe fallback
    return category

Passo 3 — Construa o roteador

O roteador conecta o classificador aos modelos. Crie router.py:

"""router.py — routes questions to the model matching their complexity."""
import os, time
from complexity_classifier import classify

# === Gemini (free via AI Studio) ===
from google import genai

gemini_client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

# === Groq (free — uncomment to use as alternative) ===
# from groq import Groq
# groq_client = Groq()

# === Ollama (local — uncomment to use as alternative) ===
# from openai import OpenAI
# ollama_client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")

# More detailed system prompt for the "large" tier
DETAILED_SYSTEM_PROMPT = """\
You are an expert assistant. Answer with step-by-step reasoning
(Chain-of-Thought). First analyze the question, then present your
structured response with evidence.
"""

MODELS = {
    "SIMPLE":  {"provider": "gemini", "model": "gemini-2.0-flash-lite", "system": None},
    "MEDIUM":  {"provider": "gemini", "model": "gemini-2.0-flash",      "system": None},
    "COMPLEX": {"provider": "gemini", "model": "gemini-2.0-flash",      "system": DETAILED_SYSTEM_PROMPT},
}

# Alternative with Groq:
# MODELS = {
#     "SIMPLE":  {"provider": "groq", "model": "llama-3.1-8b-instant",      "system": None},
#     "MEDIUM":  {"provider": "groq", "model": "llama-3.3-70b-versatile",    "system": None},
#     "COMPLEX": {"provider": "groq", "model": "llama-3.3-70b-versatile",    "system": DETAILED_SYSTEM_PROMPT},
# }

# Alternative with Ollama:
# MODELS = {
#     "SIMPLE":  {"provider": "ollama", "model": "llama3.2:3b",   "system": None},
#     "MEDIUM":  {"provider": "ollama", "model": "llama3.1:8b",   "system": None},
#     "COMPLEX": {"provider": "ollama", "model": "llama3.1:8b",   "system": DETAILED_SYSTEM_PROMPT},
# }

# Rate limits per provider (req/day or req/min)
RATE_LIMITS = {
    "gemini": "1,500 req/day (free via AI Studio)",
    "groq":   "30 req/min (free)",
    "ollama": "unlimited (local)",
}

def call_model(question: str, provider: str, model: str, system: str = None) -> dict:
    """Calls the model and returns response + metadata."""
    if provider == "gemini":
        content = f"{system}\n\n{question}" if system else question
        resp = gemini_client.models.generate_content(
            model=model,
            contents=content,
        )
        return {
            "text": resp.text,
            "tokens_input": resp.usage_metadata.prompt_token_count,
            "tokens_output": resp.usage_metadata.candidates_token_count,
        }
    elif provider == "groq":
        messages = []
        if system:
            messages.append({"role": "system", "content": system})
        messages.append({"role": "user", "content": question})
        resp = groq_client.chat.completions.create(
            model=model,
            messages=messages,
        )
        return {
            "text": resp.choices[0].message.content,
            "tokens_input": resp.usage.prompt_tokens,
            "tokens_output": resp.usage.completion_tokens,
        }
    elif provider == "ollama":
        messages = []
        if system:
            messages.append({"role": "system", "content": system})
        messages.append({"role": "user", "content": question})
        resp = ollama_client.chat.completions.create(
            model=model,
            messages=messages,
        )
        return {
            "text": resp.choices[0].message.content,
            "tokens_input": resp.usage.prompt_tokens,
            "tokens_output": resp.usage.completion_tokens,
        }

def route(question: str) -> dict:
    """Classifies, routes and returns response with full metadata."""
    complexity = classify(question)
    config = MODELS[complexity]

    start_time = time.time()
    result = call_model(
        question, config["provider"], config["model"], config.get("system")
    )
    latency = time.time() - start_time

    return {
        "question": question,
        "complexity": complexity,
        "model": config["model"],
        "provider": config["provider"],
        "response": result["text"],
        "tokens_input": result["tokens_input"],
        "tokens_output": result["tokens_output"],
        "latency_s": round(latency, 3),
    }

if __name__ == "__main__":
    r = route("What is the capital of France?")
    print(f"[{r['complexity']}] {r['provider']}/{r['model']} — {r['latency_s']}s")
    print(r["response"][:200])

Passo 4 — Construa o script de comparação

Crie compare.py para rodar os 50 casos do P2 em três modos e coletar métricas:

"""compare.py — compares always-large vs always-small vs router."""
import json, statistics
from router import route, call_model, calculate_cost, MODELS
import time

# Load the 50 test cases from P2
with open("../p2_prompt/test_cases.json") as f:
    cases = json.load(f)

def run_mode(name: str, model_override: str | None = None):
    """Runs all cases in a mode and collects metrics."""
    results = []
    for case in cases:
        question = case["input"]
        start_time = time.time()

        if model_override:
            # Fixed mode: always the same model
            config = MODELS[model_override]
            resp = call_model(question, config["provider"], config["model"])
            cost = calculate_cost(config["model"], resp["tokens_input"], resp["tokens_output"])
            model_used = config["model"]
        else:
            # Router mode
            r = route(question)
            resp = {"text": r["response"], "tokens_input": r["tokens_input"],
                    "tokens_output": r["tokens_output"]}
            cost = r["cost_usd"]
            model_used = r["model"]

        latency = time.time() - start_time
        results.append({
            "cost": cost,
            "latency": latency,
            "model": model_used,
            # Add your quality metric here (e.g.: evaluator score from P3)
        })

    costs = [r["cost"] for r in results]
    latencies = [r["latency"] for r in results]
    return {
        "mode": name,
        "total_cost": sum(costs),
        "avg_cost": statistics.mean(costs),
        "latency_p50": statistics.median(latencies),
        "latency_p95": sorted(latencies)[int(len(latencies) * 0.95)],
        "results": results,
    }

# Run the three configurations
large  = run_mode("Always large",  "COMPLEX")
small  = run_mode("Always small",  "SIMPLE")
router = run_mode("Router")

# Display comparison
print(f"{'Mode':<20} {'Total cost':>12} {'p95 latency':>14}")
print("-" * 50)
for m in [large, small, router]:
    print(f"{m['mode']:<20} ${m['total_cost']:>10.6f} {m['latency_p95']:>12.3f}s")

# Monthly projection (example: 10,000 calls/month)
CALLS_PER_MONTH = 10_000
factor = CALLS_PER_MONTH / len(cases)
print(f"\nMonthly projection ({CALLS_PER_MONTH:,} calls):")
for m in [large, small, router]:
    print(f"  {m['mode']}: ${m['total_cost'] * factor:.2f}/month")

# Save results
with open("results/cost_analysis.json", "w") as f:
    json.dump({"large": large, "small": small, "router": router}, f, indent=2)

Passo 5 — Teste cache de contexto

Cache de contexto é quando o provedor reutiliza prefixos repetidos de prompt para cobrar menos. Se o seu prompt de sistema é sempre o mesmo, os tokens dele podem ser cacheados automaticamente.

OpenAI — o cache é automático para prompts longos (a partir de 1024 tokens). Verifique no campo usage.prompt_tokens_details.cached_tokens da resposta. Não precisa mudar código.

Anthropic — use cache_control para marcar blocos que devem ser cacheados:

# Context caching with Anthropic
resp = anthropic_client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=1024,
    system=[
        {
            "type": "text",
            "text": "Your long system prompt here...",
            "cache_control": {"type": "ephemeral"},  # mark for caching
        }
    ],
    messages=[{"role": "user", "content": question}],
)
# Cached tokens appear in resp.usage.cache_read_input_tokens
print(f"Cached tokens: {resp.usage.cache_read_input_tokens}")
print(f"Cache creation tokens: {resp.usage.cache_creation_input_tokens}")

Vertex AI (Trilha B) — use a API de context caching para prompts muito longos (32k+ tokens):

# Context caching with Vertex AI
from google import genai
from google.genai.types import Content, Part

client = genai.Client(vertexai=True, project="YOUR_PROJECT", location="us-central1")

# Create the cache (valid for 1 hour by default)
cache = client.caches.create(
    model="gemini-2.5-pro",
    contents=[Content(parts=[Part(text="Your long context here...")])],
    config={"display_name": "cache-p4", "ttl": "3600s"},
)

# Use the cache in subsequent calls
resp = client.models.generate_content(
    model="gemini-2.5-pro",
    contents="User question",
    config={"cached_content": cache.name},
)

Track C — Gemini (AI Studio, free tier) — context caching works via the same google-genai SDK. The API is identical to the Vertex AI example above, but you authenticate with an API key instead of a project:

# Context caching with Gemini AI Studio (Track C)
from google import genai
from google.genai.types import Content, Part
import os

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

# Create the cache (valid for 1 hour by default)
cache = client.caches.create(
    model="gemini-2.0-flash",
    contents=[Content(parts=[Part(text="Your long system context here...")])],
    config={"display_name": "cache-p4", "ttl": "3600s"},
)

# Use the cache in subsequent calls
response = client.models.generate_content(
    model="gemini-2.0-flash",
    contents="User question here",
    config={"cached_content": cache.name},
)
print(response.text)

Track C — Groq and Ollama — neither Groq nor Ollama currently supports context caching. For these providers, the optimization strategy is different: keep your system prompt short and concise, and rely on the fast inference speed (Groq) or unlimited local throughput (Ollama) to compensate. If you need caching benefits with free providers, use Gemini AI Studio as your primary provider.

Compare o custo com e sem cache para o mesmo conjunto de perguntas e registre a diferença.

Passo 6 — Preencha a tabela, projete e conclua

Use os resultados do compare.py para preencher a tabela de comparação abaixo. Calcule a projeção mensal com o volume real esperado (ou use 10.000 chamadas como referência). Escreva uma conclusão honesta: o roteador compensa ou não? Por quê?

Quando roteamento não vale a pena

Nem sempre um roteador compensa. Calcule antes de construir:

Exemplo com números reais: suponha 10.000 chamadas/mês, prompt médio de 500 tokens de input e 200 de output.

CenárioModeloCusto mensal
Tudo no grandeclaude-sonnet-4 ($3/M in, $15/M out)$15.00 + $3.00 = $18.00
Tudo no pequenogpt-4o-mini ($0.15/M in, $0.60/M out)$0.75 + $1.20 = $1.95
Roteador (70% pequeno, 30% grande)mix~$6.76

Se a qualidade do modelo pequeno já é suficiente para o seu caso, a economia do roteador ($6.76 vs $1.95) não justifica a complexidade extra. O roteador só compensa quando:

  • O modelo grande é significativamente melhor para os casos complexos
  • A distribuição de complexidade é mista (nem tudo simples, nem tudo complexo)
  • O classificador é preciso o bastante (erros de classificação desperdiçam dinheiro ou qualidade)
  • O volume mensal é alto o suficiente para que a diferença de custo importe

reporte isso. Situações em que não compensa:
