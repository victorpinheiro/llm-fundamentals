P7 — Agente com Ferramentas

Módulo: Módulo 8 — Agentes e Uso de Ferramentas · Tempo: 24–30h · Degrau 3

Pré-condição

Justifique por escrito:

Esta tarefa exige decisão dinâmica de múltiplas etapas, em que a
sequência não pode ser determinada de antemão?

Se não exige, o correto é cadeia de prompts. Documente a justificativa
antes de começar.

Duas etapas — não pule a primeira

Etapa 1 — laço manual

Construa o laço de raciocínio e ação sem framework. Apenas o SDK do
modelo, chamada de função e um laço no seu código.

Você precisa saber o que um framework faz antes de deixá-lo fazer.

Etapa 2 — com framework

Mesma funcionalidade, agora com o framework de orquestração da sua trilha.

Escreva a comparação:
- Quanto código foi economizado?
- O que ficou mais difícil de depurar?
- O que o framework entrega de graça?

Trilha B: confirme a versão do kit antes de começar — houve reescrita
com mudanças incompatíveis. Ver Trilha B — Plataforma Corporativa do Google Cloud.

Ferramentas

Reaproveite os projetos anteriores:

Ferramenta Origem
Buscar documentação P5
Buscar tarefas P6
Criar tarefa P6
Calcular nova — cálculo nunca no modelo

Modos de falha — cada um vira teste

  • Uso incorreto de ferramenta — ferramenta falha, agente se recupera?
  • Deriva de raciocínio — tarefa longa mantém o objetivo?
  • Laço infinito — limite existe e funciona?
  • Estouro de contexto — histórico é comprimido?
  • Explosão de custo — orçamento por execução corta?
  • Injeção via ferramenta — resultado com instrução é ignorado?

Humano no laço

Defina quais ações exigem confirmação e implemente.
Criar rascunho é reversível. Enviar comunicação externa não é.

O que é o padrão ReAct

ReAct (Reasoning + Acting) é o padrão fundamental de agentes com LLM. A ideia é simples: em vez de o modelo responder de uma vez, ele alterna entre pensar e agir em um laço.

A cada iteração, o modelo recebe a pergunta e o histórico de ações anteriores. Ele decide: "preciso de mais informação?" Se sim, escolhe uma ferramenta e os argumentos. Seu código executa a ferramenta e devolve o resultado ao modelo. Ele pensa de novo. Quando tem informação suficiente, dá a resposta final.

O laço tem quatro partes:

  1. Observar — o modelo recebe a pergunta (ou o resultado da última ferramenta)
  2. Raciocinar — o modelo decide o próximo passo
  3. Agir — seu código executa a ferramenta escolhida
  4. Repetir — até o modelo retornar uma resposta final (sem tool_use) ou atingir o limite

É por isso que a Etapa 1 exige construir o laço manualmente: você precisa entender cada parte antes de entregar o controle a um framework.

Passo a passo

Passo 1 — Construir o laço manual (ReAct)

Implemente o laço completo usando apenas o SDK do modelo. Sem framework, sem abstração. O código abaixo é funcional — adapte para suas ferramentas.

Trilha A — Anthropic (tool use)

"""p7_agent/manual/loop_anthropic.py — Manual ReAct loop with Anthropic"""
import anthropic, json

client = anthropic.Anthropic()  # ANTHROPIC_API_KEY in environment
MODEL = "claude-sonnet-4-20250514"
MAX_ITERATIONS = 10

# ── Tool definitions ─────────────────────────────────────
tools = [
    {
        "name": "document_search",
        "description": "Search the knowledge base (P5 RAG). Returns relevant excerpts with source.",
        "input_schema": {
            "type": "object",
            "properties": {
                "query": {"type": "string", "description": "Question or search terms"}
            },
            "required": ["query"],
        },
    },
    {
        "name": "task_search",
        "description": "Search existing tasks in the tracker (P6). Useful for checking duplicates.",
        "input_schema": {
            "type": "object",
            "properties": {
                "query": {"type": "string", "description": "Search terms"}
            },
            "required": ["query"],
        },
    },
    {
        "name": "task_create",
        "description": "Create a new task in the tracker. IRREVERSIBLE — requires confirmation.",
        "input_schema": {
            "type": "object",
            "properties": {
                "title": {"type": "string"},
                "body": {"type": "string"},
            },
            "required": ["title", "body"],
        },
    },
    {
        "name": "calculator",
        "description": "Evaluate a math expression. Use for any calculation — never calculate in your head.",
        "input_schema": {
            "type": "object",
            "properties": {
                "expression": {"type": "string", "description": "Valid Python expression, e.g. '(150 * 0.3) + 45'"}
            },
            "required": ["expression"],
        },
    },
]

# ── Functions that execute the tools ─────────────────────
def execute_tool(name: str, args: dict) -> str:
    if name == "document_search":
        from p5_rag.retriever import search
        results = search(args["query"])
        return json.dumps([{"text": r["text"], "source": r.get("url", "")} for r in results])

    elif name == "task_search":
        from p6_integration.tasks.github_issues import search_issues_sync
        results = search_issues_sync(args["query"])
        return json.dumps([{"title": r["title"], "url": r["html_url"]} for r in results])

    elif name == "task_create":
        # ⚠ Human confirmation (Step 3)
        print(f"\n⚠ The agent wants to create a task: {args['title']}")
        if input("Confirm? (y/n): ").lower() != "y":
            return json.dumps({"error": "Action cancelled by user"})
        from p6_integration.tasks.github_issues import create_issue_sync
        result = create_issue_sync(args["title"], args["body"])
        return json.dumps(result)

    elif name == "calculator":
        # Safe evaluation — numeric expressions only
        allowed = set("0123456789+-*/.() ")
        expr = args["expression"]
        if not all(c in allowed for c in expr):
            return json.dumps({"error": "Expression contains disallowed characters"})
        try:
            result = eval(expr, {"__builtins__": {}})
            return json.dumps({"result": result})
        except Exception as e:
            return json.dumps({"error": str(e)})

    return json.dumps({"error": f"Tool {name} not found"})

# ── The ReAct loop ───────────────────────────────────────
def run_agent(user_message: str) -> str:
    messages = [{"role": "user", "content": user_message}]

    for i in range(MAX_ITERATIONS):
        response = client.messages.create(
            model=MODEL,
            max_tokens=4096,
            tools=tools,
            messages=messages,
        )

        # If the model didn't request tools, this is the final answer
        if response.stop_reason == "end_turn":
            return "".join(b.text for b in response.content if b.type == "text")

        # Process each tool_use in the response
        messages.append({"role": "assistant", "content": response.content})

        tool_results = []
        for block in response.content:
            if block.type == "tool_use":
                print(f"  [{i+1}] Calling {block.name}({json.dumps(block.input, ensure_ascii=False)[:80]})")
                result = execute_tool(block.name, block.input)
                tool_results.append({
                    "type": "tool_result",
                    "tool_use_id": block.id,
                    "content": result,
                })

        messages.append({"role": "user", "content": tool_results})

    return "Iteration limit reached."

# ── Usage ────────────────────────────────────────────────
if __name__ == "__main__":
    question = "What is the procedure for requesting vacation? If no task exists about this, create one."
    print(run_agent(question))

                    "title": {"type": "string"},
                    "body": {"type": "string"},
                },
                "required": ["title", "body"],
            },
        },
    },
    {

        "function": {
            "name": "calculator",

                "type": "object",

            })

    return "Iteration limit reached."

Trilha B — Vertex AI (function calling)

"""p7_agent/manual/loop_vertex.py — Manual ReAct loop with Vertex AI"""
from google.cloud import aiplatform
from vertexai.generative_models import GenerativeModel, Tool, FunctionDeclaration
import json

# Initialize: gcloud auth application-default login
aiplatform.init(project="YOUR_PROJECT", location="us-central1")

# ── Function declarations ────────────────────────────────
func_declarations = [
    FunctionDeclaration(
        name="document_search",
        description="Search the knowledge base.",
        parameters={"type": "object", "properties": {"query": {"type": "string"}}, "required": ["query"]},
    ),
    FunctionDeclaration(
        name="task_search",
        description="Search existing tasks.",
        parameters={"type": "object", "properties": {"query": {"type": "string"}}, "required": ["query"]},
    ),
    FunctionDeclaration(
        name="task_create",
        description="Create a new task. IRREVERSIBLE.",
        parameters={"type": "object", "properties": {"title": {"type": "string"}, "body": {"type": "string"}}, "required": ["title", "body"]},
    ),
    FunctionDeclaration(
        name="calculator",
        description="Evaluate a math expression.",
        parameters={"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]},
    ),
]

vertex_tool = Tool(function_declarations=func_declarations)
model = GenerativeModel("gemini-2.0-flash", tools=[vertex_tool])

def run_agent(user_message: str) -> str:
    chat = model.start_chat()
    response = chat.send_message(user_message)

    for i in range(10):
        fc = response.candidates[0].content.parts[0].function_call
        if not fc or not fc.name:
            return response.candidates[0].content.parts[0].text

        print(f"  [{i+1}] Calling {fc.name}")
        result = execute_tool(fc.name, dict(fc.args))

        from vertexai.generative_models import Part
        response = chat.send_message(
            Part.from_function_response(name=fc.name, response={"result": result})
        )

    return "Iteration limit reached."

Track C — Gemini AI Studio (function calling)

"""p7_agent/manual/loop_gemini.py — ReAct loop with Gemini AI Studio (free)"""
import os, json
from google import genai
from google.genai import types

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
MODEL = "gemini-2.0-flash"
MAX_ITERATIONS = 10

# -- Tool declarations using Gemini types ----------------------------
tool = types.Tool(function_declarations=[
    types.FunctionDeclaration(
        name="document_search",
        description="Search the knowledge base (P5 RAG). Returns relevant excerpts with source.",
        parameters=types.Schema(
            type="OBJECT",
            properties={
                "query": types.Schema(type="STRING", description="Search query"),
            },
            required=["query"],
        ),
    ),
    types.FunctionDeclaration(
        name="task_search",
        description="Search existing tasks in the tracker (P6).",
        parameters=types.Schema(
            type="OBJECT",
            properties={
                "query": types.Schema(type="STRING", description="Search terms"),
            },
            required=["query"],
        ),
    ),
    types.FunctionDeclaration(
        name="task_create",
        description="Create a new task. IRREVERSIBLE - requires confirmation.",
        parameters=types.Schema(
            type="OBJECT",
            properties={
                "title": types.Schema(type="STRING"),
                "body": types.Schema(type="STRING"),
            },
            required=["title", "body"],
        ),
    ),
    types.FunctionDeclaration(
        name="calculator",
        description="Evaluate a math expression. Use for any calculation.",
        parameters=types.Schema(
            type="OBJECT",
            properties={
                "expression": types.Schema(type="STRING", description="Valid Python expression, e.g. '(150 * 0.3) + 45'"),
            },
            required=["expression"],
        ),
    ),
])

# execute_tool is the same function from the examples above

def run_agent(user_message: str) -> str:
    """ReAct loop using Gemini function calling."""
    config = types.GenerateContentConfig(tools=[tool])
    contents = [types.Content(role="user", parts=[types.Part.from_text(user_message)])]

    for i in range(MAX_ITERATIONS):
        response = client.models.generate_content(
            model=MODEL, contents=contents, config=config,
        )
        candidate = response.candidates[0]

        # Check for function calls
        function_calls = [p for p in candidate.content.parts if p.function_call]
        if not function_calls:
            # No tool call -- this is the final answer
            return candidate.content.parts[0].text

        # Process each function call
        contents.append(candidate.content)
        for part in function_calls:
            fc = part.function_call
            print(f"  [{i+1}] Calling {fc.name}({json.dumps(dict(fc.args), ensure_ascii=False)[:80]})")
            result = execute_tool(fc.name, dict(fc.args))
            contents.append(types.Content(
                role="user",
                parts=[types.Part.from_function_response(
                    name=fc.name, response={"result": result},
                )],
            ))

    return "Iteration limit reached."

Passo 2 — Definir as 4 ferramentas

As ferramentas já aparecem nos exemplos acima. O ponto importante para cada uma:

"""p7_agent/tools/tools.py — Implementation of the 4 tools"""
import json

# ── 1. document_search — reuses RAG from P5 ─────────────
def document_search(query: str) -> str:
    from p5_rag.retriever import search
    results = search(query, top_k=5)
    return json.dumps([
        {"text": r["text"][:500], "source": r.get("url", ""), "score": r.get("score", 0)}
        for r in results
    ])

# ── 2. task_search — reuses the tracker from P6 ─────────
def task_search(query: str) -> str:
    from p6_integration.tasks.github_issues import search_issues_sync
    results = search_issues_sync(query)
    return json.dumps([
        {"title": r["title"], "url": r["html_url"], "state": r["state"]}
        for r in results[:5]
    ])

# ── 3. task_create — reuses the tracker from P6 ─────────
# ⚠ This tool is IRREVERSIBLE → requires human confirmation (Step 3)
def task_create(title: str, body: str) -> str:
    from p6_integration.tasks.github_issues import create_issue_sync
    result = create_issue_sync(title, body)
    return json.dumps(result)

# ── 4. calculator — safe calculation ─────────────────────
def calculator(expression: str) -> str:
    """Evaluate a numeric expression. Never let the model calculate on its own."""
    allowed = set("0123456789+-*/.() ")
    if not all(c in allowed for c in expression):
        return json.dumps({"error": "Disallowed characters"})
    try:
        result = eval(expression, {"__builtins__": {}})
        return json.dumps({"result": float(result)})
    except Exception as e:
        return json.dumps({"error": str(e)})

Por que o calculator usa eval restrito? O modelo não é confiável para aritmética. Qualquer cálculo deve ser feito por código. O eval com __builtins__ vazio e validação de caracteres é seguro para expressões numéricas simples. Para expressões mais complexas, use a biblioteca asteval ou simpleeval.

Passo 3 — Adicionar confirmação humana

Divida as ferramentas em duas categorias:

  • Reversíveis (executar direto): document_search, task_search, calculator
  • Irreversíveis (exigir confirmação): task_create, e qualquer ferramenta que envie email, poste mensagem, ou altere dados
"""Human confirmation pattern — add to execute_tool"""

IRREVERSIBLE_TOOLS = {"task_create"}

def execute_tool_safe(name: str, args: dict) -> str:
    if name in IRREVERSIBLE_TOOLS:
        print(f"\n{'='*50}")
        print(f"⚠ IRREVERSIBLE ACTION: {name}")
        print(f"Arguments: {json.dumps(args, indent=2, ensure_ascii=False)}")
        print(f"{'='*50}")
        confirmation = input("Execute? (y/n): ").strip().lower()
        if confirmation != "y":
            return json.dumps({
                "status": "cancelled",
                "reason": "Action cancelled by user"
            })

    return execute_tool(name, args)

Passo 4 — Reconstruir com framework

Trilha A — OpenAI Agents SDK

"""p7_agent/framework/agent_openai_sdk.py"""
from agents import Agent, Runner, function_tool

# Tools become decorators
@function_tool
def document_search(query: str) -> str:
    """Search the knowledge base (P5 RAG)."""
    from p5_rag.retriever import search
    import json
    results = search(query, top_k=5)
    return json.dumps([{"text": r["text"][:500], "source": r.get("url", "")} for r in results])

@function_tool
def task_search(query: str) -> str:
    """Search existing tasks in the tracker (P6)."""
    from p6_integration.tasks.github_issues import search_issues_sync
    import json
    return json.dumps([{"title": r["title"], "url": r["html_url"]} for r in search_issues_sync(query)[:5]])

@function_tool
def calculator(expression: str) -> str:
    """Evaluate a math expression."""
    import json
    allowed = set("0123456789+-*/.() ")
    if not all(c in allowed for c in expression):
        return json.dumps({"error": "Disallowed characters"})
    return json.dumps({"result": eval(expression, {"__builtins__": {}})})

agent = Agent(
    name="P7 Agent",
    instructions="You are an assistant that answers questions using the knowledge base and the task tracker.",
    tools=[document_search, task_search, calculator],
)

# The framework handles the loop, history, and streaming
result = Runner.run_sync(agent, "What is the procedure for vacation?")
print(result.final_output)

Track C — LangGraph with Groq (free)

"""p7_agent/framework/agent_langgraph_groq.py — LangGraph agent with Groq (free)"""
from langgraph.prebuilt import create_react_agent
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool
import os

@tool
def document_search(query: str) -> str:
    """Search the knowledge base (P5 RAG)."""
    from p5_rag.retriever import search
    import json
    return json.dumps([{"text": r["text"][:500]} for r in search(query)])

@tool
def calculator(expression: str) -> str:
    """Evaluate a math expression."""
    import json
    return json.dumps({"result": eval(expression, {"__builtins__": {}})})

# Groq is OpenAI-compatible, so ChatOpenAI works with a custom base_url
model = ChatOpenAI(
    model="llama-3.3-70b-versatile",
    api_key=os.getenv("GROQ_API_KEY"),
    base_url="https://api.groq.com/openai/v1",
)
agent = create_react_agent(model, [document_search, calculator])

result = agent.invoke({"messages": [("user", "What is 15% of 3200?")]})
print(result["messages"][-1].content)

Note: LangGraph works with any OpenAI-compatible provider. For Ollama, use ChatOpenAI(model="llama3.2", base_url="http://localhost:11434/v1", api_key="ollama"). For Gemini, use ChatGoogleGenerativeAI(model="gemini-2.0-flash") from langchain-google-genai.

# ── 1. Incorrect tool use ────────────────────────────────

    assert result  # Must not fail silently
    assert "error" in result.lower() or "not found" in result.lower()

# ── 2. Reasoning drift ──────────────────────────────────
def test_goal_drift():
    """Long task maintains the original goal."""
    result = run_agent(
        "First search for the vacation procedure, then check if there is "
        "an open task about it, and finally give me the summary."
    )
    # The result should mention vacation, not have drifted to another topic
    assert "vacation" in result.lower()

# ── 3. Infinite loop ────────────────────────────────────
def test_max_iterations():
    """Iteration limit works."""
    # Use a query that can generate a loop (e.g., "keep searching until you find")
    result = run_agent("Keep searching for information until you find everything about topic X")
    # Should stop at MAX_ITERATIONS, not run forever
    assert result is not None

def test_context_overflow():
    """Long history does not break the agent."""

def test_tool_injection():
    """Tool result with malicious instruction is ignored."""
    from unittest.mock import patch

    # Simulate document_search returning content with injection
    malicious_result = json.dumps([{
