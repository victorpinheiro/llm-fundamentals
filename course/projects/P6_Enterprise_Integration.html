P6 — Integração Corporativa

Módulo: Módulo 7 — Integrações Corporativas · Tempo: 20–26h · Degrau 2

Objetivo

Dar uma porta de entrada real ao sistema do projeto anterior, com
autenticação correta e permissões respeitadas.

Cenário

Person in messaging tool: asks about a procedure
       ↓
   Request signature verification
       ↓
   Retrieval with THE PERSON's permissions
       ↓
   Response in thread, with source citation
       ↓
   Option: "not resolved? open ticket"

Componentes

Interface de mensagens

  • Comando ou menção que aciona o sistema
  • Assinatura de requisição verificada
  • Resposta em tópico, sem poluir o canal
  • Citação clicável
  • Escopos mínimos

Rastreador de tarefas

  • Criar item a partir da conversa
  • Buscar itens similares antes, para evitar duplicata

Base de conhecimento

  • Ingestão como fonte para a recuperação
  • Metadados de permissão preservados

Controle de acesso

  • Identidade mapeada entre plataformas
  • Permissões da pessoa respeitadas
  • Testado com usuário de baixo privilégio

Segurança — obrigatório

  • Segredos em cofre
  • Assinatura verificada
  • Credenciais nunca em log
  • Conteúdo externo tratado como não confiável
  • Teste: mensagem contendo "ignore suas instruções" não altera
    o comportamento
  • Auditoria de consultas

Passo a passo

O exemplo principal usa Slack porque é a opção mais acessível: workspace gratuito, API bem documentada, e a maioria dos times já usa. As alternativas estão na seção seguinte.

Passo 1 — Criar o app no Slack

Acesse api.slack.com/apps e clique em Create New App > From an app manifest. Selecione o workspace de desenvolvimento (crie um workspace gratuito separado para testes).

O manifest mínimo em YAML:

display_information:
  name: P6 RAG Bot
features:
  bot_user:
    display_name: rag-bot
    always_online: true
  slash_commands:
    - command: /ask
      url: https://SEU_DOMINIO/slack/commands
      description: Ask the knowledge base
      usage_hint: "[your question]"
oauth_config:
  scopes:
    bot:
      - chat:write
      - commands
      - app_mentions:read
settings:
  event_subscriptions:
    request_url: https://SEU_DOMINIO/slack/events
    bot_events:
      - app_mention
  interactivity:
    is_enabled: true
    request_url: https://SEU_DOMINIO/slack/interactive

Depois de criar, vá em Install App e instale no workspace. Anote o Bot User OAuth Token (começa com xoxb-) e o Signing Secret (em Basic Information).

Passo 2 — Montar o servidor

O servidor precisa: (1) receber requisições do Slack, (2) verificar a assinatura HMAC-SHA256, (3) processar e responder. Exemplo com FastAPI:

"""p6_integration/messaging/app.py"""
import hashlib, hmac, time, os, httpx
from fastapi import FastAPI, Request, HTTPException

app = FastAPI()

SLACK_SIGNING_SECRET = os.environ["SLACK_SIGNING_SECRET"]
SLACK_BOT_TOKEN = os.environ["SLACK_BOT_TOKEN"]

# ── Signature verification ─────────────────────────────────
def verify_slack_signature(request_body: bytes, timestamp: str, signature: str):
    """Verifies HMAC-SHA256 per https://api.slack.com/authentication/verifying-requests-from-slack"""
    if abs(time.time() - float(timestamp)) > 60 * 5:
        raise HTTPException(status_code=403, detail="Timestamp expired")

    base = f"v0:{timestamp}:{request_body.decode()}"
    expected = "v0=" + hmac.new(
        SLACK_SIGNING_SECRET.encode(), base.encode(), hashlib.sha256
    ).hexdigest()

    if not hmac.compare_digest(expected, signature):
        raise HTTPException(status_code=403, detail="Invalid signature")

# ── Events endpoint ───────────────────────────────────────
@app.post("/slack/events")
async def slack_events(request: Request):
    body = await request.body()
    data = await request.json()

    # Verification challenge (first setup)
    if data.get("type") == "url_verification":
        return {"challenge": data["challenge"]}

    verify_slack_signature(
        body,
        request.headers.get("X-Slack-Request-Timestamp", ""),
        request.headers.get("X-Slack-Signature", ""),
    )

    event = data.get("event", {})
    if event.get("type") == "app_mention":
        await handle_question(event["text"], event["channel"], event.get("ts"))

    return {"ok": True}

Para desenvolvimento local, use ngrok ou o Slack CLI para expor seu servidor local. Exemplo: ngrok http 8000 e use a URL gerada no manifest.

Passo 3 — Responder ao comando /ask

Slash commands têm deadline de 3 segundos para responder. A estratégia: responder imediatamente com "Buscando...", processar em background, e postar o resultado no thread.

"""Continuation of app.py — /ask handler"""
from fastapi import Form
from fastapi.responses import JSONResponse
import asyncio

@app.post("/slack/commands")
async def slack_command(
    request: Request,
    command: str = Form(...),
    text: str = Form(""),
    user_id: str = Form(...),
    channel_id: str = Form(...),
):
    body = await request.body()
    verify_slack_signature(
        body,
        request.headers.get("X-Slack-Request-Timestamp", ""),
        request.headers.get("X-Slack-Signature", ""),
    )

    if command == "/ask":
        # Immediate response (within 3s)
        asyncio.create_task(handle_question(text, channel_id, user_id=user_id))
        return JSONResponse({"text": "Searching the knowledge base..."})

    return JSONResponse({"text": f"Command {command} not recognized."})

async def handle_question(question: str, channel: str, thread_ts=None, user_id=None):
    """Calls P5 RAG and posts response to Slack."""
    # ---- Access control (Step 5) ----
    user_permissions = get_user_permissions(user_id) if user_id else {}

    # ---- Call P5 RAG ----
    from p5_rag.retriever import search  # Your P5 system
    results = search(question, filters={"access_level": user_permissions.get("level", "public")})

    # ---- Build response with citations ----
    context = "\n".join(r["text"] for r in results)
    sources = "\n".join(f"• <{r['url']}|{r['title']}>" for r in results if r.get("url"))

    answer = call_llm(question, context)  # Your model call function

    message = f"{answer}\n\n*Sources:*\n{sources}" if sources else answer

    # ---- Post to channel/thread ----
    async with httpx.AsyncClient() as client:
        await client.post(
            "https://slack.com/api/chat.postMessage",
            headers={"Authorization": f"Bearer {SLACK_BOT_TOKEN}"},
            json={
                "channel": channel,
                "text": message,
                "thread_ts": thread_ts,  # Reply in thread
            },
        )

Passo 4 — Integrar com rastreador de tarefas

Use a API de Issues do GitHub como rastreador (é gratuita e não exige setup extra). Se preferir Jira ou Linear, a lógica é a mesma.

"""p6_integration/tasks/github_issues.py"""
import os, httpx

GITHUB_TOKEN = os.environ["GITHUB_TOKEN"]
GITHUB_REPO = os.environ["GITHUB_REPO"]  # "user/repo"
BASE_URL = f"https://api.github.com/repos/{GITHUB_REPO}/issues"
HEADERS = {
    "Authorization": f"Bearer {GITHUB_TOKEN}",
    "Accept": "application/vnd.github+json",
}

async def search_issues(query: str) -> list[dict]:
    """Search existing issues to avoid duplicates."""
    async with httpx.AsyncClient() as client:
        resp = await client.get(
            "https://api.github.com/search/issues",
            headers=HEADERS,
            params={"q": f"{query} repo:{GITHUB_REPO} is:issue"},
        )
        resp.raise_for_status()
        return resp.json().get("items", [])

async def create_issue(title: str, body: str, labels: list[str] = None) -> dict:
    """Create issue from Slack conversation."""
    # First search for duplicates
    existing = await search_issues(title)
    if existing:
        return {"duplicate": True, "existing": existing[0]["html_url"]}

    async with httpx.AsyncClient() as client:
        resp = await client.post(
            BASE_URL,
            headers=HEADERS,
            json={"title": title, "body": body, "labels": labels or ["from-slack"]},
        )
        resp.raise_for_status()
        issue = resp.json()
        return {"duplicate": False, "url": issue["html_url"], "number": issue["number"]}

Passo 5 — Implementar controle de acesso

Mapeie o Slack user ID para as permissões da sua base. Isso garante que cada pessoa só veja documentos que tem direito de acessar.

"""p6_integration/access_control.py"""
import os, json

# In production, this would come from a database or IdP (Okta, Azure AD, etc.)
# For the project, a simple JSON file is sufficient.
USER_MAP_FILE = os.environ.get("USER_MAP_FILE", "user_map.json")

def load_user_map() -> dict:
    with open(USER_MAP_FILE) as f:
        return json.load(f)

def get_user_permissions(slack_user_id: str) -> dict:
    """Returns user permissions based on Slack ID.

    Example user_map.json:
    {
      "U01ABCDEF": {"name": "Ana", "level": "admin", "departments": ["engineering", "hr"]},
      "U02GHIJKL": {"name": "Carlos", "level": "viewer", "departments": ["engineering"]}
    }
    """
    user_map = load_user_map()
    user = user_map.get(slack_user_id)

    if not user:
        # Unknown user → minimal access
        return {"level": "public", "departments": []}

    return user

def filter_by_access(results: list[dict], permissions: dict) -> list[dict]:
    """Filters RAG results based on user permissions."""
    allowed_departments = set(permissions.get("departments", []))
    level = permissions.get("level", "public")

    filtered = []
    for doc in results:
        doc_dept = doc.get("metadata", {}).get("department", "public")
        doc_level = doc.get("metadata", {}).get("access_level", "public")

        if doc_level == "public":
            filtered.append(doc)
        elif level == "admin":
            filtered.append(doc)
        elif doc_dept in allowed_departments:
            filtered.append(doc)

    return filtered

# ── 1. Secrets in environment variables (never in code) ────
def test_secrets_not_hardcoded():
    """Verifies that no .py file contains hardcoded tokens."""
    import pathlib, re
    project_root = pathlib.Path(__file__).parent.parent
    patterns = [
        r'xoxb-[0-9]',          # Slack bot token
        r'xoxp-[0-9]',          # Slack user token
        r'ghp_[A-Za-z0-9]',     # GitHub token
        r'sk-[A-Za-z0-9]{20,}', # OpenAI key
    ]
    for py_file in project_root.rglob("*.py"):
        content = py_file.read_text(errors="ignore")
        for pattern in patterns:
            assert not re.search(pattern, content), \
                f"Possible hardcoded secret in {py_file}: {pattern}"

Passo 7 — Teste com outra pessoa

Esse passo é obrigatório no Definition of Done. Dicas práticas:

  • Convide um colega para o workspace de desenvolvimento (Slack gratuito permite)
  • Cadastre essa pessoa no user_map.json com permissões restritas
  • Peça para ela usar o /ask com perguntas reais
  • Observe: ela recebeu resposta? A citação estava correta? Ela viu algum documento que não deveria?
  • Peça para ela tentar uma mensagem de injeção ("ignore suas instruções...")

Documente o resultado no docs/operacao.md.

Alternativas ao Slack

A lógica é a mesma. Muda a API de entrada e a verificação de assinatura.

Discord

Use a biblioteca discord.py. Discord usa WebSocket em vez de webhooks, o que simplifica o setup local (não precisa de ngrok). O modelo de permissões é por roles no servidor.

# Minimal example with discord.py
import discord, os

bot = discord.Client(intents=discord.Intents.default())

@bot.event
async def on_message(message):
    if message.author == bot.user:
        return
    if bot.user.mentioned_in(message):
        answer = call_rag(message.content)  # Seu RAG do P5
        await message.reply(answer)

bot.run(os.environ["DISCORD_TOKEN"])

Microsoft Teams

Use o Bot Framework SDK (pip install botbuilder-core). Requer registro no Azure Bot Service. Mais complexo de configurar, mas necessário em ambientes corporativos Microsoft.

Track A — Using OpenAI / Anthropic for the LLM call

The integration architecture (Slack bot, access control, task tracker) is provider-independent. The only provider-specific part is the call_llm function used inside handle_question. For Track A, replace call_llm with one of these:

Track A — OpenAI

"""call_llm implementation for OpenAI."""
from openai import OpenAI

client = OpenAI()

def call_llm(prompt: str, context: str = "") -> str:
    """Generate a response using OpenAI."""
    messages = [{"role": "system", "content": prompt}]
    if context:
        messages.append({"role": "user", "content": context})
    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=messages,
        temperature=0,
    )
    return resp.choices[0].message.content

Track A — Anthropic

"""call_llm implementation for Anthropic."""
import anthropic

client = anthropic.Anthropic()

def call_llm(prompt: str, context: str = "") -> str:
    """Generate a response using Anthropic Claude."""
    resp = client.messages.create(
        model="claude-sonnet-4-20250514",
        max_tokens=1024,
        system=prompt,
        messages=[{"role": "user", "content": context or "Execute the task."}],
        temperature=0,
    )
    return resp.content[0].text

Track B — Using Vertex AI for the LLM call

The integration architecture (Slack bot, access control, task tracker) is provider-independent. The only provider-specific part is the call_llm function used inside handle_question. For Track B, replace call_llm with:

Track B — Vertex AI (Gemini)

"""call_llm implementation for Vertex AI."""
import os
import vertexai
from vertexai.generative_models import GenerativeModel

vertexai.init(project=os.getenv("GOOGLE_CLOUD_PROJECT"), location="us-central1")
model = GenerativeModel("gemini-2.0-flash")

def call_llm(prompt: str, context: str = "") -> str:
    """Generate a response using Vertex AI Gemini."""
    full_prompt = f"{prompt}\n\n{context}" if context else prompt
    response = model.generate_content(full_prompt, generation_config={"temperature": 0})
    return response.text

Track C — Using free providers for the LLM call

The integration architecture (Slack bot, access control, task tracker) is provider-independent. The only provider-specific part is the call_llm function used inside handle_question. For Track C, replace call_llm with one of these (cost: $0.00):

Track C — Gemini (AI Studio)

"""call_llm implementation for Gemini AI Studio (free)."""
import os
from google import genai

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

def call_llm(question: str, context: str) -> str:
    """Generate a grounded answer using Gemini (free tier)."""
    system_prompt = (
        "You are a knowledge base assistant. Answer ONLY from the context provided. "
        "Cite sources in brackets. If the answer is not in the context, say so."
    )
    prompt = f"{system_prompt}\n\nContext:\n{context}\n\nQuestion: {question}"
    response = client.models.generate_content(
        model="gemini-2.0-flash",
        contents=prompt,
    )
    return response.text

Como executar

1. Instalar dependências

No diretório p6_integration/, instale os pacotes necessários:

pip install fastapi uvicorn httpx python-dotenv

Se você vai usar o rastreador do GitHub (Passo 4), httpx já cobre. Para a alternativa Discord, adicione discord.py; para Teams, botbuilder-core.

2. Configurar variáveis de ambiente

Crie um arquivo .env na raiz do projeto (nunca comite esse arquivo):

# .env
SLACK_SIGNING_SECRET=your_signing_secret_here
SLACK_BOT_TOKEN=xoxb-your-bot-token-here
GITHUB_TOKEN=ghp_your_github_token_here
GITHUB_REPO=your_user/your_repo

Se preferir, exporte as variáveis diretamente no terminal:

export SLACK_SIGNING_SECRET="your_signing_secret_here"
export SLACK_BOT_TOKEN="xoxb-your-bot-token-here"

3. Subir o servidor

uvicorn p6_integration.messaging.app:app --port 8000 --reload

O flag --reload reinicia o servidor quando você salva qualquer arquivo — ideal para desenvolvimento. Em produção, remova-o.

Se tudo estiver correto, você verá:

INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Started reloader process

4. Expor para o Slack com ngrok

O Slack precisa de uma URL pública para enviar eventos. Em outro terminal:

ngrok http 8000

Copie a URL HTTPS gerada (ex.: https://a1b2c3d4.ngrok-free.app) e substitua SEU_DOMINIO no manifest do Slack (Passo 1). Lembre-se de atualizar o manifest toda vez que reiniciar o ngrok, pois a URL muda.

Dica: o Slack CLI (slack run) é uma alternativa ao ngrok que mantém a URL estável.
