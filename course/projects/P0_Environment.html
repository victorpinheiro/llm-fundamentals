P0 — Ambiente e Primeira Chamada

Antes do Módulo 1 · Tempo: 2–3h

Objetivo

Ter ambiente funcionando e fazer a primeira chamada com sucesso.
Projeto pequeno de propósito — o valor é remover atrito antes do
conteúdo começar.

Passo a passo

1. Crie o ambiente virtual

Abra o terminal na raiz do seu projeto e execute:

python -m venv .venv

Ative o ambiente:

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Windows (cmd)
.venv\Scripts\activate.bat

# macOS / Linux
source .venv/bin/activate

Confirme que está ativo — o prompt do terminal deve mostrar (.venv) no início da linha.

2. Instale as dependências

Com o ambiente ativo, instale os pacotes necessários:

pip install google-genai groq openai python-dotenv

O que cada pacote faz:

  • google-genai — SDK do Google Gemini (provedor principal, gratuito via AI Studio)
  • groq — SDK da Groq (alternativa gratuita, modelos Llama)
  • openai — SDK compatível com OpenAI, usado também para conectar ao Ollama (local)
  • python-dotenv — carrega variáveis do arquivo .env

Salve as dependências para reprodutibilidade:

pip freeze > requirements.txt

3. Configure as credenciais

Crie um arquivo .env na raiz do projeto. Nunca comite este arquivo.

# .env
GEMINI_API_KEY=...sua-chave-aqui...
GROQ_API_KEY=gsk_...sua-chave-aqui...

Obtenha suas chaves gratuitamente em:

  • Gemini (principal): aistudio.google.com/apikey — 1.500 requisições/dia grátis, 15 RPM
  • Groq (alternativa): console.groq.com/keys — 30 RPM grátis

Ollama (opcional — execução local)

Se quiser rodar modelos localmente sem depender de API externa, instale o Ollama e baixe um modelo:

ollama pull llama3.2

Ollama não precisa de chave de API — roda na sua máquina em http://localhost:11434.

4. Proteja suas credenciais

Crie o .gitignore antes de qualquer git add:

# .gitignore
.env
.venv/
__pycache__/
*.pyc

Crie também um .env.example sem valores reais, para documentar quais variáveis são esperadas:

# .env.example — copie para .env e preencha com seus valores
OPENAI_API_KEY=
ANTHROPIC_API_KEY=
GOOGLE_CLOUD_PROJECT=
GOOGLE_CLOUD_LOCATION=

5. Configure alertas de orçamento

Antes de escrever qualquer código, configure um limite de gasto. Você vai esquecer uma chamada em loop algum dia — o alerta é o que impede uma conta de centenas de dólares.

  • OpenAI: Configurar limites de uso — defina um limite mensal (ex: US$10 para começar).
  • Anthropic: Console Anthropic — Plans — configure o limite de gasto.
  • Google Cloud: Criar alertas de orçamento — crie um alerta no console de faturamento.

6. Escreva o hello.py

Este é o momento da verdade: uma chamada real ao modelo. Escolha o código da sua trilha.

Trilha A — OpenAI

# hello.py — Track A (OpenAI)
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI()  # uses OPENAI_API_KEY from .env automatically

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Say 'Hello, world!' and explain in one sentence what an LLM is."}
    ],
    temperature=0,
)

print(response.choices[0].message.content)
print(f"\nTokens used: {response.usage.total_tokens}")

Trilha A — Anthropic

# hello.py — Track A (Anthropic)
import os
from dotenv import load_dotenv
import anthropic

load_dotenv()

client = anthropic.Anthropic()  # uses ANTHROPIC_API_KEY from .env automatically

response = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=256,
    messages=[
        {"role": "user", "content": "Say 'Hello, world!' and explain in one sentence what an LLM is."}
    ],
    temperature=0,
)

print(response.content[0].text)
print(f"\nTokens — input: {response.usage.input_tokens}, output: {response.usage.output_tokens}")

Trilha B — Vertex AI

# hello.py — Track B (Vertex AI)
import os
from dotenv import load_dotenv
import vertexai
from vertexai.generative_models import GenerativeModel

load_dotenv()

vertexai.init(
    project=os.getenv("GOOGLE_CLOUD_PROJECT"),
    location=os.getenv("GOOGLE_CLOUD_LOCATION", "us-central1"),
)

model = GenerativeModel("gemini-2.0-flash")

response = model.generate_content(
    "Say 'Hello, world!' and explain in one sentence what an LLM is.",
    generation_config={"temperature": 0},
)

print(response.text)
print(f"\nTokens — input: {response.usage_metadata.prompt_token_count}, "
      f"output: {response.usage_metadata.candidates_token_count}")

Track C — Gemini (AI Studio)

# hello_gemini.py — Track C (Gemini via AI Studio, free tier)
import os
from dotenv import load_dotenv
from google import genai

load_dotenv()

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

response = client.models.generate_content(
    model="gemini-2.0-flash",
    contents="Say 'Hello, world!' and explain in one sentence what an LLM is.",
)

print(response.text)
print(f"\nTokens — input: {response.usage_metadata.prompt_token_count}, "
      f"output: {response.usage_metadata.candidates_token_count}")

Track C — Groq

# hello_groq.py — Track C (Groq, free tier, OpenAI-compatible)
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    base_url="https://api.groq.com/openai/v1",  # free, no credit card
    api_key=os.environ.get("GROQ_API_KEY"),
)

# NOTE: Groq models change frequently. Check available models:
# curl -s https://api.groq.com/openai/v1/models \
#   -H "Authorization: Bearer $GROQ_API_KEY" | python -m json.tool
response = client.chat.completions.create(
    model="openai/gpt-oss-20b",
    max_tokens=256,
    messages=[
        {"role": "user", "content": "Say 'Hello, world!' and explain in one sentence what an LLM is."}
    ],
)

print(response.choices[0].message.content)
print(f"\nTokens — input: {response.usage.prompt_tokens}, output: {response.usage.completion_tokens}")

Track C — Ollama

# hello_ollama.py — Track C (Ollama, local, OpenAI-compatible)
from openai import OpenAI

# Ollama runs locally — no API key needed
client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama",
)

response = client.chat.completions.create(
    model="llama3.2",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Say 'Hello, world!' and explain in one sentence what an LLM is."},
    ],
    temperature=0,
)

print(response.choices[0].message.content)
print(f"\nTokens used: {response.usage.total_tokens}")

7. Execute e valide

python hello.py

Se tudo estiver correto, você verá a resposta do modelo e a contagem de tokens. Se receber erro de autenticação, revise o passo 3.

8. Inicialize o repositório

git init
git add .gitignore .env.example hello.py requirements.txt
git commit -m "P0: ambiente configurado e primeira chamada funcionando"

Note que .env não está na lista de arquivos adicionados — e deve aparecer no git status como ignorado.
