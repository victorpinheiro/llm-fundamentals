P0 — Ambiente e Primeira Chamada

Antes do Módulo 1 · Tempo: 2–3h

Objetivo

Ter ambiente funcionando e fazer a primeira chamada com sucesso.
Projeto pequeno de propósito — o valor é remover atrito antes do
conteúdo começar.

Passo a passo

1. Crie o ambiente virtual

Abra o terminal na raiz do seu projeto e execute:

python -m venv .venv

Ative o ambiente:

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Windows (cmd)
.venv\Scripts\activate.bat

# macOS / Linux
source .venv/bin/activate

Confirme que está ativo — o prompt do terminal deve mostrar (.venv) no início da linha.

2. Instale as dependências

Com o ambiente ativo, instale os pacotes necessários para a sua trilha:

# Trilha A — OpenAI + Anthropic
pip install openai anthropic python-dotenv

# Trilha B — Google Cloud / Vertex AI
pip install google-cloud-aiplatform python-dotenv

Salve as dependências para reprodutibilidade:

pip freeze > requirements.txt

3. Configure as credenciais

Crie um arquivo .env na raiz do projeto. Nunca comite este arquivo.

Trilha A — OpenAI + Anthropic

# .env
OPENAI_API_KEY=sk-proj-...sua-chave-aqui...
ANTHROPIC_API_KEY=sk-ant-...sua-chave-aqui...

Obtenha suas chaves em:

  • OpenAI: platform.openai.com/api-keys
  • Anthropic: console.anthropic.com/settings/keys

Trilha B — Google Cloud / Vertex AI

# .env
GOOGLE_CLOUD_PROJECT=meu-projeto-id
GOOGLE_CLOUD_LOCATION=us-central1

A Trilha B usa Application Default Credentials (ADC) — nunca chave de API. Configure com:

gcloud auth application-default login

Se ainda não tem o gcloud instalado, siga o guia de instalação do Google Cloud CLI.

4. Proteja suas credenciais

Crie o .gitignore antes de qualquer git add:

# .gitignore
.env
.venv/
__pycache__/
*.pyc

Crie também um .env.example sem valores reais, para documentar quais variáveis são esperadas:

# .env.example — copie para .env e preencha com seus valores
OPENAI_API_KEY=
ANTHROPIC_API_KEY=
GOOGLE_CLOUD_PROJECT=
GOOGLE_CLOUD_LOCATION=

5. Configure alertas de orçamento

Antes de escrever qualquer código, configure um limite de gasto. Você vai esquecer uma chamada em loop algum dia — o alerta é o que impede uma conta de centenas de dólares.

  • OpenAI: Configurar limites de uso — defina um limite mensal (ex: US$10 para começar).
  • Anthropic: Console Anthropic — Plans — configure o limite de gasto.
  • Google Cloud: Criar alertas de orçamento — crie um alerta no console de faturamento.

6. Escreva o hello.py

Este é o momento da verdade: uma chamada real ao modelo. Escolha o código da sua trilha.

Trilha A — OpenAI

# hello.py — Trilha A (OpenAI)
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI()  # usa OPENAI_API_KEY do .env automaticamente

resposta = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "Você é um assistente útil."},
        {"role": "user", "content": "Diga 'Olá, mundo!' e explique em uma frase o que é um LLM."}
    ],
    temperature=0,
)

print(resposta.choices[0].message.content)
print(f"\nTokens usados: {resposta.usage.total_tokens}")

Trilha A — Anthropic

# hello.py — Trilha A (Anthropic)
import os
from dotenv import load_dotenv
import anthropic

load_dotenv()

client = anthropic.Anthropic()  # usa ANTHROPIC_API_KEY do .env automaticamente

resposta = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=256,
    messages=[
        {"role": "user", "content": "Diga 'Olá, mundo!' e explique em uma frase o que é um LLM."}
    ],
    temperature=0,
)

print(resposta.content[0].text)
print(f"\nTokens — entrada: {resposta.usage.input_tokens}, saída: {resposta.usage.output_tokens}")

Trilha B — Vertex AI

# hello.py — Trilha B (Vertex AI)
import os
from dotenv import load_dotenv
import vertexai
from vertexai.generative_models import GenerativeModel

load_dotenv()

vertexai.init(
    project=os.getenv("GOOGLE_CLOUD_PROJECT"),
    location=os.getenv("GOOGLE_CLOUD_LOCATION", "us-central1"),
)

modelo = GenerativeModel("gemini-2.0-flash")

resposta = modelo.generate_content(
    "Diga 'Olá, mundo!' e explique em uma frase o que é um LLM.",
    generation_config={"temperature": 0},
)

print(resposta.text)
print(f"\nTokens — entrada: {resposta.usage_metadata.prompt_token_count}, "
      f"saída: {resposta.usage_metadata.candidates_token_count}")

7. Execute e valide

python hello.py

Se tudo estiver correto, você verá a resposta do modelo e a contagem de tokens. Se receber erro de autenticação, revise o passo 3.

8. Inicialize o repositório

git init
git add .gitignore .env.example hello.py requirements.txt
git commit -m "P0: ambiente configurado e primeira chamada funcionando"

Note que .env não está na lista de arquivos adicionados — e deve aparecer no git status como ignorado.
