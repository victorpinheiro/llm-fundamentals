Referência — Seleção de Modelo

Complemento ao Módulo 4 — Seleção de Modelo e Custo.

Planilha de decisão

Preencha antes de escolher:

Latência máxima aceitável:      _______
Piso de qualidade:              _______
Volume diário estimado:         _______
Teto de custo mensal:           _______
Exige raciocínio extenso?       _______
Restrição de dados/jurisdição:  _______

→ Camada indicada:              _______
→ Justificativa:                _______

Sem essas respostas, qualquer escolha de modelo é chute.

Protocolo de comparação

Para comparar modelos de forma honesta:

  1. Mesmo conjunto de casos para todos
  2. Mesmo prompt para todos (a menos que esteja testando o prompt)
  3. Temperatura zero em tarefas determinísticas
  4. Múltiplas execuções para medir variância
  5. Medir: qualidade, latência por percentil, custo, taxa de erro

Preencher:

Modelo Qualidade p50 p95 Custo/1k Erros

Roteamento

entrada → classificador (modelo mais barato)
        → simples  → modelo pequeno
        → média    → modelo intermediário
        → complexa → modelo grande

Meça o roteamento contra as duas linhas de base: sempre grande e
sempre pequeno. Sem isso você não sabe se ganhou.

Sinais de que não vale a pena:
- Economia inferior a 20%
- Classificador erra com frequência
- Latência adicional relevante
- Distribuição concentrada numa só categoria

Concluir que não vale é resultado legítimo.
